# Authoritative model prices (RR-50)

`model-prices.json` contains only prices passing every source-evidence guard. The 2026-10-07 round-4 fetch fills all five known Meta chat IDs and both Z.ai chat IDs. Both DeepSeek IDs remain unfilled because the current official table never states USD; a dollar sign is insufficient. Meta and Z.ai list optional provider web-search charges, excluded under the round-4 lead ruling only with source-bound request-builder proof and a compiled guard that rejects native tools before dispatch. Public pricing and linked public billing documentation are reviewed in full; account transaction dashboards are recorded separately and never used as evidence of unseen billing terms. No login or identity confirmation was attempted. The manifest records every model's outcome, exact fee quotes and capture receipts. Capped requests stop before transport until an exact model has a current official price and authoritative input/output limits. Unknown cost receipts retain durable holds; changing month or restarting does not release them.

OpenRouter capped requests read the public `https://openrouter.ai/api/v1/models` endpoint at runtime. The request binds the returned exact model and sets `provider.max_price` (USD per million prompt/completion tokens, USD per request) and the output limit. Auto routing, conditional overrides and unhandled extra charges are unavailable to the flat text budget. Contract source, inspected 2026-10-07: [official OpenRouter SDK](https://github.com/OpenRouterTeam/typescript-sdk/tree/3c88d7075ba91b7b7fbca33073126873823131ed/src/models), `model.ts`, `publicpricing.ts`, `providerpreferences.ts`. No live rates were retrieved in the cloud.

`model-price-ids.json` binds each API ID to the exact official display text and source URL. No case folding, fuzzy matching, or implicit aliasing is performed. Scope is the nine known text chat IDs offered by DeepSeekAPI, MetaAPI and ZaiAPI; unknown dynamic IDs remain unfilled. Meta Standard and Contributor are different exact API IDs, not interchangeable billing tiers.

Each extraction mapping specifies `service`, `model`, `sourceUrl`, `modelCell`, `inputCell`, `outputCell`, `tokenUnitQuote`, and optionally `cachedInputCell`, `requestCell`, `maximumInputCell`, `maximumOutputCell`. Cell coordinates are `[table, row, column]`, starting at zero. `checks` bind the exact headers and condition labels. DeepSeek spans expand into a rectangular grid, repeating the exact source text; overlapping, incomplete, excessive, or out-of-table spans fail closed. Meta's `meta-marketing` parser reads the official product page's div layout and streamed HTML fragments without executing scripts or interpreting JavaScript/Flight objects. Header/row changes fail closed. `/docs/pricing` returns an empty shell and is not used as a price source.

`inputAlternatives`, `outputAlternatives`, `cachedInputAlternatives`, and `requestAlternatives` list every applicable conditional cell. Nonempty alternatives require verbatim `billingConditionQuotes`; generation selects the highest numeric rate independently for each charge. DeepSeek maps both peak and off-peak cells. Never average, use an off-peak default, or import a historic rate from a news page. `storageCell` records Z.ai's conditional `Limited-time Free`; a paid storage charge cannot be represented by the flat token/request catalog and leaves that model unfilled. Unknown future storage rates are never guessed.

If no request-fee cell exists, an exact `tokenOnlyQuote` establishing no request fees remains valid. The round-3 lead ruling also accepts **"none listed on the official pricing page"** when the complete token table and linked public billing terms have been reviewed and no applicable separate fee, minimum or surcharge is listed. `completeListReview` binds a checked-in review to every official page's full human-readable content SHA-256. Each build re-fetches those pages, verifies the review hashes and link coverage, and generates request-fee evidence with the raw capture URL, UTC date and SHA-256. Changed content, omitted public terms, unavailable billing terms or a login shell cannot establish absence. Source request-fee cells still use the highest applicable numeric rate. A variable per-query/use charge cannot be guessed into a flat per-request fee.

The round-4 ruling permits one specific exception: Meta's per-query and Z.ai's per-use **provider web-search tool** charges do not apply to Marrow's requests. Each excluded charge retains its exact quote, URL, capture date/SHA and the statement **"applies only to the provider's web-search tool, which Marrow never enables"**. `provider-tool-proof.json` binds each provider to exact reviewed builder, provider payload, dispatch guard and regression-test source hashes plus file:line citations. Missing, wrong-provider, incomplete or stale proof leaves the model unfilled. A generic optional/inapplicable flag still fails the original fee test. Only the two known account transaction dashboard URLs can be classified separately; public billing terms cannot be bypassed that way.

`ProviderToolBillingGuard` enforces the reviewed Meta/Z.ai payload field allow-list and requires every tool to be a local `function`. It runs before spend reservation and at the final transport boundary, for capped and uncapped requests. Native search, code interpreter, unknown tools/options and nested option additions stop before transport. Local functions/MCP functions named web_search remain local functions and incur no provider search fee. The regression inspects 252 real payloads across all seven models, nine effort inputs, tool modes and normal/Hydra heads, including skill and MCP definitions; future-tool tests assert no HTTP dispatch. After a builder/guard/test edit, review the request shapes and rerun these tests before updating proof hashes; never automatically approve a changed builder by refreshing hashes alone.

USD and per-million-token units must be explicit. Separate `currencyEvidence` and `tokenUnitEvidence` can quote the same provider's official documentation when the pricing layout splits these facts across pages. Each quote is matched verbatim and receives its own capture/date/hash. Meta uses its current official terms' U.S. Dollars statement and the pricing/rate-limits page's per-1M-token header. No currency is inferred from a dollar sign. Bounds still require exact integer token counts; K/M bounds are not guessed. The price-source host allow-list remains unchanged; supplemental evidence uses a finite provider-owned host allow-list including linked public billing hosts. No redirect, authentication or CLI configuration workaround is used.

Every generation re-fetches official HTTPS pages, records UTC retrieval dates, SHA-256 hashes and mappings, and writes the schema-backed JSON, compiled `ModelPriceData.cs`, and `model-price-fetch-manifest.json`. With a reviewed `identityMap`, failures leave only affected models unfilled and remove their previous rates; other valid models are published. Each manifest row records filled/unfilled status, exact identity, billing conditions, highest selected cell, and rejection reasons. Empty maps or duplicate identities abort before replacing outputs. Legacy maps without `identityMap` retain their original all-or-nothing preservation behavior. Review and commit all generated outputs, then rebuild. Runtime accepts prices for less than 24 hours after retrieval and rejects future dates. Refresh and rebuild daily and whenever an official price changes; stale data stops capped requests. An installed build has no automatic page-price update, so releases needing longer operation require a separately reviewed updater. Missing limits can support spend accounting but cannot authorize a capped request.
