## UI contract records

Exact values. Do not round, restyle or substitute. Where a value is macOS-delegated, say so.

- **UI-USAGE-005** Usage popover and floating usage panel / Context window row label (label)
  - text, verbatim: `Context window`
  - geometry: Left item of an HStack; Spacer(minLength: 12) to its right. The row is the first child of the panel's VStack, so it sits at the 16 point content inset.
  - type: System size 13, applied to the whole row.
  - colour: Chrome.secondaryText.
  - states: absent when the usage has no fraction or no windowTokens
- **UI-USAGE-006** Usage popover and floating usage panel / Context window value (label)
  - text, verbatim: `<used> / <window> (<n>%)`
  - geometry: Trailing item of the context row.
  - type: System size 13 with monospaced digits.
  - colour: Chrome.secondaryText.
  - states: always present when the row is present
- **UI-USAGE-007** Usage popover and floating usage panel / Context window bar (progress bar)
  - geometry: Full content width, 5 points tall, 10 points below the context row. Fill is at least 5 points wide whenever the fraction is above zero.
  - type: None.
  - colour: Track Chrome.overlay(0.1), which is the label colour at 10 percent. Fill Chrome.accent, unconditionally.
  - states: fraction 0: no fill drawn; fraction > 0: at least a 5 point nub; fraction clamped to 1: never overflows the track; never turns warning or danger, unlike a plan-limit bar
- **UI-USAGE-008** Usage popover and floating usage panel / Lead or Heads section header (label)
  - text, verbatim: `Lead · <provider display name> | Heads · <provider display name>`
  - geometry: HStack with 6 points of spacing; a 13 x 13 provider icon then the text; 8 points of bottom padding.
  - type: System size 12, semibold.
  - colour: Chrome.primaryText; the icon is the provider's own asset.
  - states: absent unless a distinct heads provider is set; the whole section is absent when that provider exposes neither limits nor credits
- **UI-USAGE-035** Usage popover and floating usage panel / Section divider (separator)
  - geometry: Full content width; 14 points of padding above and below in the panel body, or 14 points above only between windows and banked resets.
  - type: None.
  - colour: Platform separator colour.
  - states: before limits and before credits in the single-provider layout: only when the context block was drawn; before the Lead section: only when the context block was drawn; before the Heads section: when the context block was drawn or the lead exposes limits or credits; between limits and credits inside a provider section: always when both show; between windows and banked resets: only when there is at least one window
