- **Cancellation:** Not cancellable once started; it is a detached task that the launch sequence awaits.
- **Windows path:** Same single launch-time sweep in the same position in the warm-up order. Do not turn it into a periodic background task: the source runs it once.
- **Verify by:** interaction test asserting one sweep per launch and none afterwards
