### PR-RUNTIME-013 - ToolTitles.unwrapShell strips six shell wrappers and one level of matching quotes
- **Source:** DroppyCode/Services/Providers/ProviderSession.swift:174-186 - trims whitespace and newlines, then tests the prefixes in this order: "/bin/zsh -lc ", "/bin/bash -lc ", "bash -lc ", "zsh -lc ", "/bin/sh -c ", "sh -c "; drops the prefix, and when the remainder is at least 2 characters and begins and ends with the same quote character (single or double) drops both; when that quote was a single quote, replaces every occurrence of the three-character sequence quote-backslash-quote-quote with a single quote; returns the trimmed input when no prefix matched
- **Preconditions:** A provider reported a shell command as a tool title.
- **Action:** unwrapShell is called on the title.
- **Expected:** Exactly one prefix is removed (the first that matches, in the listed order). Only one level of quoting is stripped, and the POSIX single-quote escape is undone only for single-quoted bodies. A title with no matching prefix comes back whitespace-trimmed and otherwise untouched.
- **Persistence:** The unwrapped title is what the adapters put on a ToolCall, which is persisted.
- **Failure cases:** A remainder shorter than two characters, or with mismatched first and last quote characters, is returned with its quotes intact.
- **Cancellation:** not cancellable
- **Windows path:** Keep all six POSIX prefixes verbatim even on Windows: they appear in output produced by providers running through their own shells and in recorded fixtures. Whether a Windows interpreter prefix is added is UNK-0005 and is not this requirement's business.
- **Verify by:** unit - table test over all six prefixes, both quote characters and the escape sequence
- **Depends on UNK-0005**, which is unresolved. Implement only the part the source settles; flag the rest.

### PR-RUNTIME-014 - ToolTitles.relativePath strips a root prefix only when the root's trailing separator matches
- **Source:** DroppyCode/Services/Providers/ProviderSession.swift:188-191 - normalizedRoot is root when it ends with "/" else root + "/"; returns the path with normalizedRoot dropped when it has that prefix, else the path unchanged
- **Preconditions:** A path and a root are known.

- **Expected:** A path that is not under the root is returned whole. The comparison is a plain string prefix test with no normalization, no symlink resolution and no case folding.
- **Persistence:** None directly.
