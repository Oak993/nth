- **Windows path:** The temporary directory must exist and be usable as a working directory.
- **Verify by:** unit test over disabled, unconfigured and ordinary models

### PR-PROVCLI-170 - Copilot computes a quota percent by two branches that clamp differently, the fallback having no lower bound
- **Source:** DroppyCode/Services/Providers/CopilotSession.swift:454-456 - let remaining = snapshot["remainingPercentage"]?.double; let used = snapshot["usedRequests"]?.double ?? 0; let percent = remaining.map { max(0, min(100, 100 - $0)) } ?? min(100, used / entitlement * 100) | porting/upstream_defects.md entry 3 | porting/extracts/provider-argv-and-handshakes.md section 3.7
- **Preconditions:** A snapshot that passed the skip guard.
- **Action:** The percent is computed.
- **Expected:** Branch A, when remainingPercentage parses as a double: percent = max(0, min(100, 100 - remainingPercentage)), clamped at BOTH ends into 0 to 100, because remainingPercentage is a remaining figure and the displayed percent is its complement. Branch B, when it is absent: used = usedRequests or zero, and percent = min(100, (used / entitlement) * 100), clamped ONLY at the top. Evaluation order is the division first, then the multiplication. Branch B therefore produces a NEGATIVE percent for a negative usedRequests, which branch A could never do, and that negative value reaches the usage bar. This is an upstream defect and is reproduced, not clamped.
- **Side effects:** The computed percent reaches the usage bar
- **Persistence:** Persisted with the plan limits.
- **Failure cases:** A negative usedRequests yields a negative percent.
- **Cancellation:** not cancellable
- **Windows path:** Floating-point division and the min/max clamps must match IEEE double semantics so the boundary values agree.
- **Verify by:** unit test over both branches including a negative usedRequests and a remainingPercentage above 100
- **Upstream defect upstream_defects.md entry 3 (Copilot fallback percent branch has no lower clamp): reproduce it faithfully, do not fix it.**
