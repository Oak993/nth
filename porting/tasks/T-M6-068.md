- **Preconditions:** A turn is running, the composer is empty, no head of this lead is working, and the turn's own user row is a real user message rather than one from Hydra.
- **Action:** Escape is pressed.
- **Expected:** With any condition unmet the turn is only stopped and stays in the thread. The turn is then reverted without restoring files, so the conversation and the provider's context rewind but the files stay as the turn left them. - **Persistence:** The revert's own writes (PR-RUNTIME-172).

- **Windows path:** 200 iterations of 50 milliseconds is exact and is not the same as one 10-second sleep: it exits as soon as the runtime is idle.
- **Verify by:** integration test - both the guarded path and the full take-back
