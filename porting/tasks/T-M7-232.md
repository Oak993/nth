### PR-USAGE-028 - Reset text has three forms: minutes and hours within a day, weekday and time within six days, month and day beyond
- **Source:** DroppyCode/App/Views/Usage/UsageViews.swift:180-191 static func resetText(_ date: Date, now: Date = .now) -> String { let seconds = max(0, date.timeIntervalSince(now)); if seconds < 86_400 { let hours = Int(seconds) / 3_600; let minutes = Int(seconds) % 3_600 / 60; return hours > 0 ? - **Preconditions:** A window or a banked reset carries a date.
- **Action:** resetText(date) is evaluated against the current time.
- **Expected:** The interval is clamped at zero, so a past date reads as "in 1 min". Under 6*86400 seconds: the abbreviated weekday with hour and minute, for example "Sun 17:00". Otherwise: the abbreviated month and day, for example "Oct 4". - **Persistence:** None.
- **Failure cases:** The two date branches use Foundation format styles and follow the user's locale and 12/24-hour setting; the string is not fixed English for those two branches, unlike the month names in the token activity grid.
- **Cancellation:** not cancellable
- **Windows path:** Pure function with a platform date formatter for the last two branches. Use the OS short weekday plus short time, and short month plus day, so a locale change tracks the same way it does on macOS. The first branch is hand-built English and must not be localized.
- **Verify by:** unit test at -60, 0, 59, 60, 3599, 3600, 86399, 86400, 6*86400-1 and 6*86400 seconds out
