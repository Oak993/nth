### PR-GIT-093 - TouchedPaths.normalize returns the repository-relative form, or the path unchanged when it is not under the root
- **Source:** DroppyCode/Services/Git/TouchedPaths.swift:6-13 normalize(_:root:) - an empty path returns the empty string; the path is resolved relative to the standardized root and standardized; when it starts with the root plus a slash, that prefix is removed; otherwise it is returned as it stands
- **Preconditions:** A path an agent reported, absolute or relative.
- **Action:** It is put into repository-relative form.
- **Expected:** An empty input returns the empty string. Otherwise the path is resolved against the standardized root directory and standardized itself; the prefix is the root path with a trailing slash added when it lacks one, and when the result starts with that prefix the prefix is dropped. A path outside the root is returned unchanged, absolute, which is what lets TurnDiff test for a leading slash.
- **Side effects:** None
- **Persistence:** The results are persisted as TurnRecord.touchedPaths.
- **Failure cases:** Not applicable; normalize never rejects
- **Cancellation:** not cancellable
- **Windows path:** Platform boundary: the absolute test is a leading slash on macOS. On Windows the equivalent is a drive-letter or UNC root, and the upward walk must terminate at the drive or share root. TurnDiff's hasPrefix("/") test must be re-expressed against the same rule.
- **Verify by:** unit over an in-root relative path, an in-root absolute path and an out-of-root absolute path

### PR-GIT-094 - TouchedPaths.relative rejects a URL, a climb out of the root and anything outside the checkout
- **Source:** DroppyCode/Services/Git/TouchedPaths.swift:19-29 relative(_:root:) - `var path = path.trimmed`; `guard !path.isEmpty, !path.contains("://") else { return nil }`; `if path.hasPrefix("~") { path = (path as NSString).expandingTildeInPath }`; `let root = (root as NSString).standardizingPath`; `let absolute = path.hasPrefix("/") ? path : (root as NSString).appendingPathComponent(path)`; `let full = (absolute as NSString).standardizingPath`; `let prefix = root.hasSuffix("/") ? root : root + "/"`; `guard full.hasPrefix(prefix) else { return nil }`; `return String(full.dropFirst(prefix.count)).nilIfEmpty` | DroppyCode/Services/Git/TouchedPaths.swift:15-18 - 'A file written outside the checkout is not the thread's work, and git refuses to stage it, which used to take the whole merge down with it.'
- **Preconditions:** An agent reported editing a path.
- **Action:** The app decides whether that path is part of the checkout.
- **Expected:** The path is trimmed of whitespace and newlines. An empty result, or any path containing the literal "://", is rejected with nil. A leading tilde is expanded to the home directory. The root is standardized; a relative path is appended to it; the whole is standardized, which resolves any climb out. The result must start with the root plus a trailing slash, otherwise nil. The remainder is returned, or nil when it is empty.
- **Side effects:** None
- **Persistence:** Accepted results become TurnRecord.touchedPaths entries.
- **Failure cases:** A path outside the checkout yields nil and is not attributed to the turn
- **Cancellation:** not cancellable
- **Windows path:** Platform boundary: the absolute test must accept a drive-letter or UNC root, tilde expansion maps to the user profile, and the standardisation must resolve .. without touching the filesystem. Note a Windows path such as C:/x contains no "://" so the URL rejection still behaves.
- **Verify by:** unit over a URL, a ../ climb, a tilde path, an in-root path and the root itself

- **Failure cases:** Not applicable

### PR-GIT-096 - TouchedPaths.matches is a bidirectional slash-anchored suffix test over both the path and the old path

- **Cancellation:** not cancellable

- **Verify by:** unit over exact, forward-suffix and reverse-suffix matches, and an oldPath-only match
