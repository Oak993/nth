### PR-STORE-017 - The shared storage encoder writes ISO 8601 dates and sorted keys, and does not pretty-print
- **Source:** DroppyCode/Core/Support/Coding.swift:19-26 - JSONEncoder.storage with dateEncodingStrategy = .iso8601 and outputFormatting = [.sortedKeys] | DroppyCode/Services/Store/Storage.swift:117-118 - comment "The encoder writes the path's slashes as `\/`." then text.matches(of: #/attachments\\?\/([0-9A-Fa-f-]{36}\.[A-Za-z0-9]+)/#): the backslash is optional | project.yml:4-5 - deploymentTarget: macOS: "26.0" (the minimum macOS whose Foundation JSONEncoder writes these files)
- **Preconditions:** None.
- **Action:** Any encode through DiskWriter.
- **Expected:** Dates are written as ISO 8601 strings. Object keys are emitted in Foundation's .sortedKeys order (Coding.swift:23), which keeps successive saves byte-stable; that order is Foundation's own, and an ordinal code-unit sort is not evidence of it. Pretty printing is not enabled, so the file is one line. Forward slashes are escaped as \/ by the Foundation encoder, whose default this is. The attachment sweep does not depend on the escaping: its pattern makes the backslash optional (Storage.swift:118), so it matches the escaped and the unescaped form alike. The encoder is Foundation's JSONEncoder on macOS 26.0 or later, the deployment target (project.yml:5); its key collation, its escaping of non-ASCII and control characters and its formatting of Double values are Foundation internals that no pinned file states. The verifier's reading of Foundation (keys compared with [.numeric, .caseInsensitive, .forcedOrdering]; every non-C0 scalar written as raw UTF-8; other C0 controls as \u00XX with lowercase hex; Doubles from Double.description, such as 1e+16 and 1e-05) was not run on macOS and is UNVERIFIED (UNK-0003); the byte-compare fixture settles each point before it is asserted.
- **Persistence:** The wire format of library.json and every thread file.
- **Cancellation:** not cancellable
- **Windows path:** One shared serializer configured for ISO 8601 dates, sorted keys, no pretty printing and slash escaping. Slash escaping is kept because it is the encoder's default output, not because the sweep needs it (the sweep matches both forms, Storage.swift:118). The key comparer, the non-ASCII and control-character escaping and the number format must reproduce Foundation's JSONEncoder; an ordinal key sort and a relaxed escaper are not evidence of parity, and each is pinned only by the macOS-produced fixture.
- **Verify by:** contract fixture: byte-compare encoded output against a macOS-produced file
- **Depends on UNK-0003**, which is unresolved. Implement only the part the source settles; flag the rest.

### PR-STORE-018 - The shared storage decoder reads ISO 8601 dates
- **Source:** DroppyCode/Core/Support/Coding.swift:28-33 - JSONDecoder.storage with dateDecodingStrategy = .iso8601
- **Preconditions:** None.
- **Action:** loadLibrary and the orphan sweep’s continuation decode.
- **Expected:** Date fields are parsed as ISO 8601. Both storage coders are process-wide shared instances, built once.
- **Failure cases:** A date that is not ISO 8601 fails that field’s decode, which value(_:default:) turns into the field default rather than a failure.
- **Cancellation:** not cancellable
- **Windows path:** One shared ISO 8601 deserializer.
- **Verify by:** unit

### PR-STORE-020 - value(_:default:) turns a missing key, a null and a type mismatch alike into the default
- **Source:** DroppyCode/Core/Support/Coding.swift:3-8 - func value<T: Decodable>(_ key: Key, default fallback: @autoclosure () -> T) -> T { ((try? decodeIfPresent(T.self, forKey: key)) ?? nil) ?? fallback() }
- **Preconditions:** A keyed container is decoding an older or hand-edited file.
- **Action:** Any model decode that uses the helper.
- **Expected:** The double unwrap means all three cases collapse to the default: the key is absent, the value is JSON null, or the value is present but of the wrong type and decodeIfPresent throws. The fallback is an @autoclosure so it is only evaluated on a miss.
- **Failure cases:** This is the behaviour Library.swift:234-237 relies on for the security-relevant runtimeMode fallback: a type mismatch must not become a hard error and must not become a permissive value.
- **Cancellation:** not cancellable
- **Windows path:** One helper with exactly these three collapse cases, used by every model decoder in this area. A port that only handles the missing-key case will turn a hand-edited file into a decode failure and lose the record.
- **Verify by:** unit with all three shapes
