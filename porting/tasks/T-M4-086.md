### PR-PROVCLI-393 - Copilot lineRange renders a two-integer range, using an en dash, and reads a negative end as an open range
- **Source:** DroppyCode/Services/Providers/CopilotSession.swift:1029-1032 - private static func lineRange(_ value: JSONValue?) -> String? { guard let range = value?.array?.compactMap(\.int), range.count == 2 else { return nil }; return range[1] < 0 ? "from line \(range[0])" : "lines \(range[0])–\(range[1])" }
- **Preconditions:** A view or str_replace_editor view row is being built.
- **Action:** lineRange is applied to the view_range argument.
- **Expected:** The value must be an array whose INTEGER entries number exactly two; a nil value, a non-array, or an array that yields any count other than two after keeping only integers gives nil. With a negative second number the result is the literal "from line " followed by the first number. Otherwise it is the literal "lines " followed by the first number, then U+2013 EN DASH, then the second number - an en dash, not a hyphen and not an em dash. There are no spaces around the dash.
- **Persistence:** Part of the row detail.
- **Failure cases:** An array of three integers gives nil, not a truncated range.
- **Cancellation:** not cancellable
- **Windows path:** U+2013 is the character; a hyphen here is a defect. compactMap on .int means a mixed array of one integer and one string is rejected by the count test.
- **Verify by:** unit test - [10,20], [10,-1], [10], [10,20,30] and a non-array
