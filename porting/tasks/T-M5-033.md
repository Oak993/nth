- **Source:** DroppyCode/UI/Common/WorkingIndicators.swift:84-86 `/// Draws one still frame with plain shapes instead of hosting a layer view. For image renderers, which cannot capture AppKit views: the archive ghost is rendered this way.` with `var isStill = false` | DroppyCode/UI/Common/WorkingIndicators.swift:101-107 `if isStill { StillSpinnerCells(cells: Self.cells, columns: 2, cellSize: cellSize, tints: GradientSpin.rowTints(accent: Chrome.accentNSColor)) } else { SpinnerCells(...) }` | DroppyCode/UI/Common/WorkingIndicators.swift:112-138 `/// A spinner's cells as plain shapes, frozen at the start of the wave.` with the VStack/HStack of `Rectangle().fill(Color(nsColor: tints[row])).frame(width: cellSize, height: cellSize).opacity(GradientSpin.opacity(phase: -lag))`, both stack spacings `cellSize * 0.8`, and the lag looked up per (row, column) defaulting to 0 | porting/dead_code.md:89 records this variant as NOT dead; its call site is DroppyCode/App/Views/Sidebar/SidebarView.swift:2101 `MiniSpinner(cellSize: 2.4, isStill: true)`, the archive ghost face
- **Preconditions:** A row is being rendered into a flat image, such as the archive genie ghost.
- **Action:** The mini spinner is asked for its still form.
- **Expected:** Instead of hosting a layer-backed view, the spinner draws plain rectangles: one per cell, each the cell size square, filled with its row's tint, at the opacity the curve gives for minus that cell's lag, laid out as a vertical stack of horizontal stacks both spaced at 0.8 times the cell size. The tints are resolved at build time from the current accent. The result is a single frozen frame identical to the first frame of the wave, and it is what appears in the flying archive ghost because an image renderer cannot capture a hosted platform view. The row count is derived from the cells, and a cell missing from the lag lookup would take lag 0. The still form still carries the "Working" accessibility label, because the label is applied outside the branch.
- **Persistence:** Not persisted.
- **Cancellation:** not cancellable
- **Windows path:** If the Windows archive ghost is rendered by a mechanism that CAN capture the live indicator, this variant collapses to an implementation detail; but as long as the ghost is produced by an offscreen renderer, the frozen-shape fallback is required or the ghost shows an empty gap where the indicator was.
- **Verify by:** capture comparison of the archive ghost against a live row, asserting the indicator is present and frozen at the wave's first frame
