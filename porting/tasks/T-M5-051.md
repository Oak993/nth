## Requirements

### PR-THEME-122 - Copying a whole message walks the parsed blocks into plain text, leaving out rules and the delegation block
- **Source:** DroppyCode/UI/Markdown/SelectableMessageText.swift:466-484 MessageText.plain: parses the markdown and joins the blocks with a blank line between each | DroppyCode/UI/Markdown/SelectableMessageText.swift:486-516 append: a heading and a paragraph both contribute their inline-resolved text; a code block contributes its body verbatim unless its lower-cased language is "hydra" or its body is empty; a list contributes one line per item prefixed with "☑ ", "☐ ", "N.  " (two spaces) or "•  " (two spaces), followed by its children; a quote contributes its children with no marker; a table contributes its header then each row joined with two spaces; a rule contributes nothing | DroppyCode/UI/Markdown/SelectableMessageText.swift:518-526 inline(): image markup `![alt](url)` becomes its alt text; a link `[title](url)` with an optional title attribute becomes `title (url)`, or just the URL when the two are equal; an autolink `<scheme:...>` becomes the bare URL | DroppyCode/UI/Markdown/SelectableMessageText.swift:470-473 doc: the file keeps the name of the selectable text view it used to hold, which left with the whole-reply drag mode
- **Preconditions:** The user chooses Copy message on a reply.
- **Action:** The message is turned into plain text.
- **Expected:** Blocks are separated by one blank line. Headings lose their hashes. Links become "title (url)", or the bare URL when the title equals it; images become their alt text; angle-bracket autolinks become the bare URL. Code blocks are copied verbatim, except a hydra delegation block and an empty one, which are skipped entirely (and still consume their blank-line separator). List markers are the ballot-box characters ☑ and ☐ for checkboxes and "•" or the number, each followed by two spaces. Quote markers are dropped. Table cells are joined with two spaces. Horizontal rules produce nothing.
- **Persistence:** not persisted
- **Failure cases:** A skipped code block still contributes its blank-line separator, so a reply whose only block is a delegation card copies as a single empty line.
- **Cancellation:** not cancellable
- **Windows path:** Reproduce the marker strings exactly, including the two-space form for bullets and numbers against the one-space form for checkboxes.
- **Verify by:** contract fixture: recorded plain-text output for a message containing every block kind
