### PR-COMPOSER-149 - Choosing a model sets it on the thread, carries the stored preference, leaves any pair, and may drop the provider session
- **Source:** DroppyCode/App/Views/Composer/EffortSlider.swift:237-258 choose - switchesProvider clears providerSessionID and providerResumeAt; the effort is the stored preference's effort only when the model still offers it; fastMode is the preference's fast flag and only when the model supports fast; then leaveHydraPair, then, when the provider changed, existingRuntime(for:)?.stopSession(); then remember(model:effort:for:) and settings.defaultProvider = provider
- **Preconditions:** The model list is shown.
- **Action:** The user picks a model row.
- **Expected:** The thread takes the model; on a provider change its session id and resume point are cleared and the running session is stopped. The effort comes from the stored preference for that provider and model, dropped if that model no longer offers it; fast mode likewise. Picking a model is the choice of a model alone, so the chat leaves any pair it led with. The provider becomes the app's default provider for new chats, and the model and effort are remembered for that provider.
- **Side effects:** Stops the provider session on a provider change
- **Persistence:** Thread fields; "lastModels", "lastEfforts" and the default provider in settings.
- **Cancellation:** not cancellable
- **Windows path:** Same ordering: thread update, leave pair, stop session, remember, set default.
- **Verify by:** integration test switching provider mid-thread
