### PR-THEME-139 - The favicon cache discards every icon at 300 entries and never clears its failure set

- **Preconditions:** 300 or more favicons are cached.
- **Action:** One more icon is stored.
- **Expected:** Every cached icon is discarded in one go and the new one becomes the only entry, so every favicon in a long thread blanks and is re-fetched at once. The failure set is never cleared, so a host that failed once has no icon for the rest of the session even after a network problem clears.
- **Side effects:** A burst of re-fetches after the flush
- **Persistence:** not persisted

- **Cancellation:** not cancellable
- **Windows path:** Reproduce as a wholesale flush, not an LRU eviction: the 301st favicon really does drop all 300 (port_impacts.md entry 152).
- **Verify by:** unit: the 301st store empties the map; a failed host is not retried
