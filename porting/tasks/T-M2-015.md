### PR-HYDRA-094 - streamedDelegations(inBody:) walks UTF-8 bytes and emits each entry the moment its outermost brace closes

- **Preconditions:** A reply is streaming and its delegation opener has already arrived.
- **Action:** The body so far is walked.
- **Expected:** Rules in evaluation order: (1) skip JSON whitespace, which is exactly the four bytes space, LF, CR and tab; (2) the first non-whitespace byte must be [ , which sets isArray and is consumed, or { , which sets isArray false and is NOT consumed; anything else returns an empty, incomplete result; (3) atLineStart begins TRUE because the body starts right after the opener's newline; (4) inside a string, a backslash sets escaped and an unescaped double quote ends the string; (5) outside a string, a double quote opens one, { records entryStart when depth is 0 and increments depth, } decrements depth and at depth 0 parses the byte range entryStart through the closing brace with the JSON parser, appending the delegation when delegation(fromEntry:) yields one, and when the body is a bare object marks the result complete and returns; depth below 0 marks complete and returns; (6) ] at depth 0 marks complete and returns; (7) a backtick at depth 0 AND at line start marks complete and returns, because that is the closing fence; (8) atLineStart is set to (byte == LF) at the end of every iteration. - **Cancellation:** not cancellable

### PR-HYDRA-095 - HydraDelegationStreamParser is a stateful byte machine fed only newly appended text, keyed by turn id and entry id

- **Preconditions:** A reply is streaming and the runtime holds a parser for it.
- **Action:** Newly appended text is ingested.
- **Expected:** The machine recognises the opener through states 0-15: three backticks (states 0-2, with an extra backtick tolerated at state 3), optional spaces and tabs, case-insensitive 'hydra' (states 4-7), an optional '-sent' suffix (states 8-12, spelling s, e, n, t), optional spaces and tabs, an optional CR, then LF. - **Cancellation:** The parser is discarded when the turn ends or the message is replaced.

### PR-HYDRA-096 - The two streaming readers and the whole-message parser must agree on the order and count of the heads that go out

- **Preconditions:** A delegation block streamed in and was then re-parsed whole.
- **Action:** Both paths read the same block.
- **Expected:** For any block text, the streaming readers and the whole-message parser produce the same delegations in the same order. Entries that fail delegation(fromEntry:) are skipped by both. - **Cancellation:** not cancellable
- **Windows path:** Test the two implementations against each other over a corpus of block texts.
- **Verify by:** property test comparing the two readers over generated block texts
