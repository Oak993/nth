### PR-USAGE-085 - ContextUsage.fraction is nil without a positive window and is otherwise clamped to at most one
- **Source:** DroppyCode/Core/Models/Timeline.swift:301-304 var fraction: Double? { guard let windowTokens, windowTokens > 0 else { return nil }; return min(1, Double(usedTokens) / Double(windowTokens)) }
- **Preconditions:** A ContextUsage value exists.
- **Action:** fraction is read.
- **Expected:** nil when windowTokens is nil or zero or negative. Otherwise usedTokens divided by windowTokens, capped at 1, so the bar and the ring never exceed full. - **Cancellation:** not cancellable
- **Windows path:** Same computed property; keeping it derived preserves the implication the floating panel's predicate relies on (PR-USAGE-060).
- **Verify by:** unit test at windowTokens nil, 0, -1, and used greater than window
