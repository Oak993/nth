### PR-PROVCLI-260 - Command Code lists models from the CLI's own printed table, keeping one default
- **Source:** DroppyCode/Services/Providers/CommandCodeAPI.swift:179-234 - listModels and parseModels with the doc comment | DroppyCode/Services/Providers/CommandCodeAPI.swift:41-48 - userConfig reads <home>/.commandcode/config.json
- **Preconditions:** A resolved executable.
- **Action:** The registry loads the Command Code catalog.
- **Expected:** Shell.run(executable, ["--list-models", "--no-auto-update"], environment:, timeout: 30) runs and its STDOUT is ANSI-stripped. The user's config.json supplies the configured model from "model" and the configured efforts object from "reasoningEffort". Parsing: each line is trimmed; empty lines are skipped; lines beginning with "Available models", "Pass the full id", "cmd ", "Docs:" or "Usage" are skipped. A line matching one or more non-space characters, then TWO OR MORE spaces, then the rest, is a model row; the id must contain a hyphen or a slash or the row is skipped. The detail is the remainder trimmed, with the literal " (recommended)" and " (default)" substrings REMOVED and each setting its own flag. The option carries id, name = displayName(for: id), detail = the section header and the remaining detail joined by " · " with nils dropped, efforts = efforts(for: id), defaultEffort = the configured efforts object indexed by the id, and isDefault = recommended or CLI-default, further forced true when the id matches the configured model. A non-matching line becomes the current SECTION HEADER when it has no space and starts with an uppercase letter, or when it is shorter than 24 characters. Finally: when a configured model matches a row, every other row's isDefault is cleared and that row is MOVED to index 0; otherwise the first row already marked default becomes the only default and nothing is reordered. An empty result throws ProviderError.failed with the last lines of stderr plus stdout, or the literal "Command Code listed no models."
- **Side effects:** One short-lived child process, bounded at 30 seconds; a config file read
- **Persistence:** The registry persists the catalog.
- **Failure cases:** The exact fallback message above.
- **Cancellation:** The 30 second timeout.
- **Windows path:** ANSI stripping is load-bearing. The two-or-more-space column split is applied to text the CLI printed; a Windows console that pads differently would change which rows parse, so the real output must be captured on Windows before this is called verified. Executable identity is validated per PA-0016: PATH resolution honours PATHEXT, and a candidate whose Windows version resource identifies it as the command interpreter (CompanyName Microsoft Corporation with OriginalFilename Cmd.Exe/Cmd.Exe.MUI, or FileDescription Windows Command Processor), or which is %SystemRoot%\System32\cmd.exe or %SystemRoot%\SysWOW64\cmd.exe, is rejected and the provider reports not installed.
- **Verify by:** unit test against a captured --list-models output, plus a Windows capture comparison

### PR-PROVCLI-262 - Command Code builds a model display name by merging version digits and special-casing five token forms
- **Source:** DroppyCode/Services/Providers/CommandCodeAPI.swift:246-279 - displayName(for:) with its doc comment
- **Preconditions:** A model id.
- **Action:** displayName runs.
- **Expected:** The id is reduced to the part after its last slash, then to the part before the first colon; a ":free" anywhere in the short id contributes the suffix " Free". The remainder is split on hyphens. Then, scanning left to right, any two ADJACENT all-digit tokens are merged with a period between them and the second removed, repeatedly, so "claude-fable-5-1" reads as Fable 5.1. Each token is then mapped: "gpt" -> "GPT"; "glm" -> "GLM"; "hy3" and "hy4" -> uppercased; "v4", "v4.1" and "v2.5" -> uppercased; a token starting with a digit -> unchanged; anything else -> its first character uppercased plus the rest. Finally, when the first word is exactly "GPT" and there is more than one word, the result is "GPT-" plus the remaining words joined by single spaces plus the suffix; otherwise all words joined by single spaces plus the suffix.
- **Persistence:** Part of the persisted catalog.
- **Failure cases:** none
- **Cancellation:** not cancellable
- **Windows path:** The case changes must be invariant.
- **Verify by:** unit test over claude-sonnet-5, moonshotai/kimi-k2.7-code, gpt-5.6-terra, claude-fable-5-1 and a :free id
