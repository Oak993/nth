## Requirements

### PR-STORE-017 - The shared storage encoder writes ISO 8601 dates and sorted keys, and does not pretty-print
- **Source:** DroppyCode/Core/Support/Coding.swift:19-26 - JSONEncoder.storage with dateEncodingStrategy = .iso8601 and outputFormatting = [.sortedKeys]
- **Preconditions:** None.
- **Action:** Any encode through DiskWriter.
- **Expected:** Dates are written as ISO 8601 strings. Object keys are emitted in sorted order, which keeps successive saves byte-stable. Pretty printing is not enabled, so the file is one line. Forward slashes are escaped as \/ by the Foundation encoder, which the orphan sweep depends on.
- **Persistence:** The wire format of library.json and every thread file.
- **Cancellation:** not cancellable
- **Windows path:** One shared serializer configured for ISO 8601 dates, sorted keys, no pretty printing and slash escaping. Slash escaping must be kept: the attachment sweep matches on the escaped form.
- **Verify by:** contract fixture: byte-compare encoded output against a macOS-produced file

### PR-STORE-018 - The shared storage decoder reads ISO 8601 dates
- **Source:** DroppyCode/Core/Support/Coding.swift:28-33 - JSONDecoder.storage with dateDecodingStrategy = .iso8601
- **Preconditions:** None.
- **Action:** loadLibrary and the orphan sweep’s continuation decode.
- **Expected:** Date fields are parsed as ISO 8601. Both storage coders are process-wide shared instances, built once.
- **Failure cases:** A date that is not ISO 8601 fails that field’s decode, which value(_:default:) turns into the field default rather than a failure.
- **Cancellation:** not cancellable
- **Windows path:** One shared ISO 8601 deserializer.
- **Verify by:** unit

### PR-STORE-020 - value(_:default:) turns a missing key, a null and a type mismatch alike into the default
- **Source:** DroppyCode/Core/Support/Coding.swift:3-8 - func value<T: Decodable>(_ key: Key, default fallback: @autoclosure () -> T) -> T { ((try? decodeIfPresent(T.self, forKey: key)) ?? nil) ?? fallback() }
- **Preconditions:** A keyed container is decoding an older or hand-edited file.
- **Action:** Any model decode that uses the helper.
- **Expected:** The double unwrap means all three cases collapse to the default: the key is absent, the value is JSON null, or the value is present but of the wrong type and decodeIfPresent throws. The fallback is an @autoclosure so it is only evaluated on a miss.
- **Failure cases:** This is the behaviour Library.swift:234-237 relies on for the security-relevant runtimeMode fallback: a type mismatch must not become a hard error and must not become a permissive value.
- **Cancellation:** not cancellable
- **Windows path:** One helper with exactly these three collapse cases, used by every model decoder in this area. A port that only handles the missing-key case will turn a hand-edited file into a decode failure and lose the record.
- **Verify by:** unit with all three shapes
