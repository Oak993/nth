### PR-RUNTIME-146 - appendStreamed accepts exactly four kind-and-content pairs and reports failure for every other combination
- **Source:** DroppyCode/App/Runtime/ThreadRuntime.swift:3663-3692 - the four arms (.message with .assistant appending to message.text; .reasoning with .reasoning appending to block.text; .toolOutput with .tool calling call.appendOutput; .plan with .plan appending to plan.markdown), each assigning self = .todos([]) first, then default: return false; return true
- **Preconditions:** A flush is applying a buffer to a row.
- **Action:** appendStreamed is called on the row's content.
- **Expected:** Only the four matching pairs append. Any other combination returns false and the text is discarded with no row change and no saveRevision bump. The intermediate self = .todos([]) assignment releases the enum's reference so the string stays uniquely referenced and the append is amortized constant in the delta's length rather than copying the whole message each flush; it is an implementation device, not observable state.
- **Persistence:** Row content.
- **Failure cases:** A mismatched pair loses the text silently.
- **Cancellation:** not cancellable
- **Windows path:** The uniqueness trick is Swift-specific. Any port must still achieve amortized O(delta) appending: a naive copy per flush makes long replies quadratic.
- **Verify by:** unit - four matching pairs and at least four mismatched ones
