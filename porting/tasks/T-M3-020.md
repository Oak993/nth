### PR-STORE-062 - Attachment copies and transcodes run off the main actor and append in source order
- **Source:** DroppyCode/Services/Store/Storage.swift:161-173 - @MainActor @discardableResult static func attach(...) -> Task<Void, Never>? { ... return Task.detached(priority: .userInitiated) { let imported = batch.compactMap(importSource); let kept = await MainActor.run { let room = max(0, attachmentLimit - attachments.wrappedValue.count); attachments.wrappedValue.append(contentsOf: imported.prefix(room)); return room }; ... } }
- **Preconditions:** At least one free slot.

- **Windows path:** Same detached import, same recount on the UI thread, same order. The absence of a cancellation check inside the loop is source behaviour and is reproduced.
