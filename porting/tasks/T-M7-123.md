- **UI-GIT-025** Command palette / Toggle changes action (list)
  - text, verbatim: `Toggle changes`
  - geometry: A palette row carrying the symbol "plusminus" and the shortcut's rendered label on the trailing side.
  - type: Palette row role.
  - colour: Palette styling.
  - interactions: selection toggles the diff for the current thread
- **UI-TERM-033** Command palette / Toggle terminal action row (row)
  - text, verbatim: `Toggle terminal`
  - geometry: Appended to the actions list only when a thread is selected, before the changes and finish rows.
  - type: Palette row default.
  - colour: Palette row default.
  - states: absent (not disabled) when no thread is selected; the trailing chord label is omitted entirely when the chord has been cleared
  - interactions: run: toggles the selected thread's drawer
- **UI-WIN-028** Command palette / Dimming scrim over the whole window (overlay)
  - geometry: Fills the window edge to edge, ignoring the safe area, so it covers the title bar band too.
  - type: None.
  - colour: Black at 0.24 in dark mode, 0.08 in light mode. One fixed value read as nothing at all in dark themes, which is why it branches.
  - states: only exists while the palette is open; the palette is removed from the tree when closed
  - interactions: click anywhere closes the palette
- **UI-WIN-029** Command palette / Palette panel (popover)
  - geometry: Exactly 600 points wide, horizontally centred, top edge 72 points below the window top. Height follows the content: no scroll view, no maximum.
  - type: Inherited by its children.
  - colour: Regular glass material, untinted, clipped to a continuous rounded rectangle of radius 24.
  - states: empty query: search row plus up to six recent threads and the actions; no matches: search row plus the single Nothing matches line; matches: search row plus up to twelve rows
  - interactions: clicks inside do not dismiss; clicks outside, on the scrim, do
- **UI-WIN-030** Command palette / Palette search field (field)
  - text, verbatim: `Search threads, projects and actions`
  - geometry: Row inset 18 horizontally and 15 vertically; magnifier then 10 points then the field.
  - type: The field is the title3 type role. The magnifier takes the default symbol size.
  - colour: Magnifier in the secondary style; the field takes the default text color.
  - states: focused as soon as the palette appears; no clear button, unlike the chrome and sidebar search fields
  - interactions: typing filters and resets the selection to the first row; up and down move the selection one row, clamped, both consumed; Escape closes the whole palette (it does NOT merely clear the text); Return runs the selected row
- **UI-WIN-031** Command palette / No-matches line (label)
  - text, verbatim: `Nothing matches “<query>”`
  - geometry: Leading-aligned, full width, inset 18 horizontally with 16 points below it. Replaces the whole row list.
  - type: 13 points, system.
  - colour: Secondary style.
  - states: shown only when the computed row list is empty
  - interactions: none; not interactive
- **UI-WIN-032** Command palette / Palette result row (row)
  - geometry: Row padded 12 horizontally and 8 vertically, selected background a continuous rounded rectangle of radius 12. Contents: an 18-point icon column, 12 points, a text block with 1 point between title and subtitle, at least 8 points of space, then the chord. Rows stack 2 points apart, inset 6 points from the panel sides and 6 from its bottom.
  - type: Title at the default body size, one line. Subtitle at the caption size, one line, middle-truncated. Chord at the caption size.
  - colour: Symbol tinted with the accent when selected, secondary otherwise. Subtitle secondary. Chord tertiary. Selected background is the accent at exactly 0.16.
  - states: selected: accent background at 0.16, symbol tinted; unselected: clear background, secondary symbol; a project row shows its project mark at size 13 instead of a symbol
  - interactions: hover moves the selection to this row (entering only; leaving does not clear it); click sets the selection then runs the row; Return runs the selected row
- **UI-WIN-033** Command palette / Palette row chord label (label)
  - geometry: Trailing edge of the row, after at least 8 points of space.
  - type: Caption size.
  - colour: Tertiary style.
  - states: absent entirely when the command's chord has been cleared; absent on every thread and project row; shows the remapped chord immediately after a remap
  - interactions: none; not interactive
