### PR-STORE-108 - The last four meaningful lines of process output become the error detail
- **Source:** DroppyCode/Core/Support/Text.swift:16-24 - doc comment "The last meaningful lines of process output, for error messages." then static func lastLines(_ text: String, count: Int = 4) -> String? { let lines = stripANSI(text).split(whereSeparator: \.isNewline).map { $0.trimmingCharacters(in: .whitespaces) }.filter { !$0.isEmpty }; guard !lines.isEmpty else { return nil }; return lines.suffix(count).joined(separator: "\n") }
- **Preconditions:** A process has failed and produced output.
- **Action:** An error message is built.
- **Expected:** The output is ANSI-stripped, split on every Character whose isNewline is true (a CRLF pair is one such Character), each line trimmed of .whitespaces (tab and the Zs space separators), and empty lines dropped. - **Failure cases:** Whitespace-only output yields nil, not an empty string.
- **Cancellation:** not cancellable
