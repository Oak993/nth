### PR-PROVCLI-259 - Command Code maps eight known plan ids and reads an unfamiliar one out of its own words
- **Source:** DroppyCode/Services/Providers/CommandCodeAPI.swift:127-166 - the planNames table and planName(_:) with both doc comments
- **Preconditions:** A plan id from the billing API.
- **Action:** planName runs.
- **Expected:** A nil or empty id yields nil. The lowercased id is looked up in this exact table: "individual-go" -> "Go"; "individual-goat" -> "GOAT"; "individual-pro" -> "Pro"; "individual-pro-v1" -> "Pro"; "individual-provider" -> "Provider"; "individual-max" -> "Max 10×"; "individual-ultra" -> "Max 20×"; "teams-pro" -> "Teams Pro". The two multipliers use U+00D7. On a miss the id is split on hyphens, a leading "individual" part is dropped, and an empty remainder yields nil; otherwise each part is mapped: "goat" -> "GOAT", "pro" -> "Pro", "go" -> "Go", "max" -> "Max", "ultra" -> "Ultra", "teams" or "team" -> "Teams", a part matching one or more digits followed by a lowercase x -> those digits plus "×", and anything else -> its first character uppercased followed by the rest unchanged. The parts are joined by single spaces, so an unfamiliar plan never shows as nothing.
- **Persistence:** Part of the persisted plan limits.
- **Failure cases:** An id that is only "individual" yields nil.
- **Cancellation:** not cancellable
- **Windows path:** The lowercasing and uppercasing must be invariant. The U+00D7 characters must survive to the UI.
- **Verify by:** unit test over all eight table ids, an individual-max-20x style id and a bare unknown
