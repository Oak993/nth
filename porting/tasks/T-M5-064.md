## Requirements

### PR-THEME-081 - The finish chime is a 0.7 second rising fifth at volume 0.35 whose repeat requests are swallowed while it plays
- **Source:** DroppyCode/UI/Sound/FinishChime.swift:9-10 `private static let volume: Float = 0.35` with the comment "Well under a stock alert: it registers without cutting into whatever else is playing." | DroppyCode/UI/Sound/FinishChime.swift:12-16 the sound is built once from `ToneSynth.wave(notes: notes, partials: partials, duration: 0.7)` and its volume set | DroppyCode/UI/Sound/FinishChime.swift:18-22 `static func play() { sound?.play() }` with the comment "NSSound declines a play while one is in flight, so several threads finishing in the same moment make one chime, never a pile-up." | DroppyCode/UI/Sound/FinishChime.swift:24-28 notes: frequency 587.33 onset 0 level 0.8; frequency 880 onset 0.14 level 1
- **Preconditions:** The chime setting is on and a turn has finished.
- **Action:** The finish chime is asked to play, possibly several times at once.
- **Expected:** A 0.7 second tone plays at volume 0.35 relative to the system output: a note at 587.33 Hz at level 0.8 from time 0, joined at 0.14 seconds by a note at 880 Hz at level 1, each built from three partials (fundamental at level 1 decaying with a 0.14 second constant, the octave at 0.22 decaying at 0.06, the double octave at 0.08 decaying at 0.04). A second request while the first is still sounding is ignored, so several threads finishing together produce exactly one chime. The tone is rendered on first use, not at launch.
- **Side effects:** Plays audio on the system output device
- **Persistence:** not persisted
- **Failure cases:** The sound cannot be created: play() is a silent no-op (the optional is nil).
- **Cancellation:** not cancellable once started
- **Windows path:** Platform boundary: one shared voice per chime. The swallow-while-playing behaviour must be reproduced deliberately; a Windows API that mixes each request would turn a burst of finished turns into a pile-up, which upstream specifically avoids.
- **Verify by:** unit: constants; interaction test: two finishes in the same frame produce one chime
