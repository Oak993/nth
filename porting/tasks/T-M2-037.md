The launcher must resolve the Command Code CLI rather than the Windows interpreter (see PR-PROVREG-026). Executable identity is validated per PA-0016: PATH resolution honours PATHEXT, and a candidate whose Windows version resource identifies it as the command interpreter (CompanyName Microsoft Corporation with OriginalFilename Cmd.Exe/Cmd.Exe.MUI, or FileDescription Windows Command Processor), or which is %SystemRoot%\System32\cmd.exe or %SystemRoot%\SysWOW64\cmd.exe, is rejected and the provider reports not installed. The command string "cmd login" is not reworded: PR-PROVREG-026 is settled by PA-0016 (cmd stays a valid invocation name, with executable identity validated), and OD-0008 B6 keeps "Run `cmd login` in Terminal" verbatim. OD-0012 G2: the word Keychain in this detail becomes Credential Manager, the store the port uses (PR-PROVREG-088, 239). How a Windows Login button launches the command is PR-PROVREG-233.
- **Verify by:** interaction test plus capture comparison of the detail string against the OD-0012 G2 wording
