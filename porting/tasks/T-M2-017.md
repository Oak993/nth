### PR-SIDEBAR-157 - The library decodes projects and threads leniently, dropping any record that fails rather than failing the whole file
- **Source:** DroppyCode/Core/Models/Library.swift:266-277 Library - `projects = container.value(.projects, default: [Lenient<Project>]()).compactMap(\.value)`; `threads = container.value(.threads, default: [Lenient<ChatThread>]()).compactMap(\.value)` | DroppyCode/Core/Models/Library.swift:76-89 Project.init(from:) - id and path are required; name defaults to the path's last component, addedAt to now, isExpanded to true, scripts to empty, hydraPairID and icon to nil
- **Preconditions:** The library file is read at launch.
- **Action:** Decoding runs.
- **Expected:** A project or thread whose record cannot be decoded is dropped and the rest of the library loads. - **Cancellation:** not cancellable
- **Windows path:** The Windows decoder must be equally lenient, or one bad record would empty a user's sidebar.
- **Verify by:** decode fixture with one corrupt project and one corrupt thread.

### PR-STORE-014 - Library decoding drops individual corrupt records instead of failing the whole file
- **Source:** DroppyCode/Core/Models/Library.swift:273-277 - projects = container.value(.projects, default: [Lenient<Project>]()).compactMap(\.value); threads likewise | DroppyCode/Core/Support/Coding.swift:10-17 - struct Lenient sets value = try? Element(from: decoder) and never throws
- **Preconditions:** library.json contains one or more records that fail to decode (for example a project object with no "path").
- **Action:** App launch.
- **Expected:** Every record that decodes is kept in order; each record that fails becomes nil and is removed by compactMap. The rest of the library loads normally. Nothing is reported to the user, and the dropped records are permanently lost at the next save.
- **Side effects:** The dropped records disappear from library.json at the next save
- **Persistence:** library.json
- **Failure cases:** A missing "projects" or "threads" key yields an empty array of that kind through value(_:default:), not a decode failure.
- **Cancellation:** not cancellable
- **Windows path:** Per-element tolerant decoding with the same order-preserving drop. Do not substitute a strict decoder; a strict one would turn a single bad record into the whole-file loss described in the previous requirement.
- **Verify by:** unit with a fixture holding one good and one bad project

### PR-STORE-082 - A project needs only an id and a path to decode; everything else has a default
