- **Preconditions:** A thread has no messages and no turn is running.
- **Action:** The prompt appears and the reader clicks the project name.
- **Expected:** The two sentence forms above, verbatim, including the space before the project name and the separate question mark. The project name is dot-underlined and opens a popover listing every project with the current one checked, plus Add project… with an ellipsis character. Choosing another project moves the empty thread there with the panel slide; choosing the current one does nothing.
- **Side effects:** Add project… opens the system folder picker and, on a choice, adds the project and moves the thread into it
- **Persistence:** The thread's projectID changes.
- **Failure cases:** A cancelled folder picker leaves everything unchanged.
- **Cancellation:** not cancellable
- **Windows path:** The application icon is the app's own icon at 72 points. Add project… uses the horizontal ellipsis U+2026, not three full stops. Chrome.secondaryText is Chrome.primaryText at opacity 0.7 (ED-062, DroppyCode/UI/Chrome/Chrome.swift:79).
