### PR-HYDRAMERGE-005 - The resume sweep considers only unarchived Hydra leads touched within the last three days
- **Source:** DroppyCode/App/AppModel+HydraMerge.swift:38 - let cutoff = Date.now.addingTimeInterval(-3 * 24 * 3600) | DroppyCode/App/AppModel+HydraMerge.swift:39 - let leads = threads.filter { !$0.isArchived && hydraIsOn($0) && $0.updatedAt > cutoff }
- **Preconditions:** hydraAutoMerge on.
- **Action:** resumeHydraMerges() runs.
- **Expected:** The candidate set is every thread that is not archived, has Hydra on, and whose updatedAt is strictly greater than now minus 259200 seconds (3 * 24 * 3600). Threads outside that window are never swept, however much unmerged work they hold.
- **Persistence:** none
- **Failure cases:** A lead untouched for more than three days is silently skipped forever by the sweep; only a new finished turn on it merges its work.
- **Cancellation:** not cancellable
- **Windows path:** Same filter over the thread store.
- **Verify by:** unit test over a synthetic thread list

### PR-HYDRAMERGE-006 - The resume sweep loads each candidate runtime and skips any that is busy
- **Source:** DroppyCode/App/AppModel+HydraMerge.swift:41-43 - let runtime = self.runtime(for: lead.id); await runtime.ensureLoaded(); guard runtime.phase == .idle, !runtime.isHydraMerging, runningHydraHeads(of: lead.id) == 0 else { continue }
- **Preconditions:** A candidate lead from PR-HYDRAMERGE-005.
- **Action:** The sweep reaches that lead.
- **Expected:** Its runtime is created if needed and awaited through ensureLoaded(). The lead is skipped unless phase == .idle, isHydraMerging is false, and runningHydraHeads(of:) is 0. Leads are processed one after another, not concurrently.

- **Persistence:** none

- **Cancellation:** not cancellable
- **Windows path:** Same sequential loop; runtime hydration is the Windows thread-document load.

### PR-HYDRAMERGE-008 - The resume sweep refuses a lead with no work of its own, so Hydra being on never sweeps someone else's changes

- **Preconditions:** A lead that passed PR-HYDRAMERGE-007.

- **Expected:** The merge starts only when some completed unmerged turn has a non-empty touchedPaths, OR some head of the team has hydra info with mergedAt == nil and a non-empty landing.files. - **Cancellation:** not cancellable
- **Windows path:** Same two-branch predicate. This gate is safety-critical and must not be relaxed.
- **Verify by:** unit test with a lead whose turns touched nothing and a dirty checkout

### PR-HYDRAMERGE-010 - autoMergeHydraWork re-checks six preconditions before it starts

- **Preconditions:** autoMergeHydraWork(of:) called from any trigger.
