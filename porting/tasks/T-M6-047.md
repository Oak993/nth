### PR-LAUNCH-079 - The launch prologue and the launch callback make no network call
- **Source:** DroppyCode/App/DroppyCodeApp.swift:7-19 - no networking | DroppyCode/App/AppDelegate.swift:8-28 - the only network-capable step is UpdateChecker.shared.startBackgroundChecks(), which sleeps 8 seconds before its first call | DroppyCode/App/UpdateChecker.swift:134-135 - the launch delay precedes the first check | DroppyCode/App/AppModel.swift:262-273 - the provider refresh and catalog loads happen inside bootstrap, after the window is up
- **Preconditions:** Any normal launch.
- **Action:** The app launches.
- **Expected:** No network request is made before the main window is on screen. The first outbound traffic is whatever the provider refresh in bootstrap does, and the update check no sooner than 8 seconds after launch.
- **Persistence:** None.
- **Failure cases:** An offline machine changes nothing about the launch sequence; failures are absorbed by the provider and update areas.
- **Cancellation:** not applicable
- **Windows path:** Reproduce; no telemetry, ping or licence check may be added to the launch path.
- **Verify by:** integration test capturing outbound connections during the first 8 seconds

### PR-WIN-002 - Startup runs a fixed six-step preamble before any window or settings read
- **Source:** DroppyCode/App/DroppyCodeApp.swift:7-19 init(): DCInstallNotificationGuard(); signal(SIGPIPE, SIG_IGN); WebsiteCaptures.prepare(); LegacyMigration.run(); HangWatchdog.start(); SwitchLatency.start() | DroppyCode/App/DroppyCodeApp.swift:13 comment 'Before anything reads settings or the library.' immediately above WebsiteCaptures.prepare() and LegacyMigration.run()
- **Preconditions:** Process launch.
- **Action:** The application initializer runs.
- **Expected:** In this exact order: the notification guard is installed, SIGPIPE is ignored, the capture run prepares, the legacy migration runs, the hang watchdog starts, and the switch-latency log starts. The ordering is load-bearing: the migration must run before anything reads settings or the library.
- **Side effects:** Legacy migration may move on-disk state; Hang watchdog begins sampling the main thread
- **Persistence:** nothing persisted
- **Failure cases:** Not expressed in this file; each step owns its own failure handling
- **Cancellation:** not cancellable
- **Windows path:** Two of the six steps are macOS-only and are NOT ported: DCInstallNotificationGuard (an AppKit NSNotificationCenter exception net, dead_code.md entry 41) and signal(SIGPIPE, SIG_IGN) (Windows reports a broken pipe on the write call itself, platform_adaptations.md PA-0004). The ordering constraint for the remaining steps stands: migration before any settings or library read.
- **Verify by:** unit: startup order assertion; the two dropped steps are recorded as NOT_APPLICABLE_WITH_EVIDENCE
