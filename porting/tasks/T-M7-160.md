## Requirements

### PR-SETTINGS-019 - The settings scroll tracker freezes on movement, thaws 150ms after the last movement, and reports under one fixed pane id
- **Source:** DroppyCode/App/Views/Settings/SettingsScrollTracker.swift:9-19 - final class SettingsScrollTracker: ScrollActivityReporter with `private static let pane = UUID()`, isScrolling, isFrozen, isCoasting, settle task | DroppyCode/App/Views/Settings/SettingsScrollTracker.swift:22-37 note() - sets isScrolling and reports true to ScrollActivity once; sets isFrozen only when not coasting and not already frozen; cancels and restarts a 150ms settle task that clears isScrolling, isCoasting and isFrozen and reports false | DroppyCode/App/Views/Settings/SettingsScrollTracker.swift:41-44 coast() - sets isCoasting and clears isFrozen | DroppyCode/App/Views/Settings/SettingsScrollTracker.swift:46-55 end() - cancels the settle task, clears isFrozen and isCoasting, and reports false only if it was scrolling
- **Preconditions:** The settings window is open.
- **Action:** Scroll frames arrive, then stop; or the window closes.
- **Expected:** The first movement frame marks the pane as scrolling and reports it to ScrollActivity under one fixed pane identifier shared by both scroll views. Movement also freezes the rows unless the tracker is coasting. Every movement frame cancels and restarts a 150 millisecond timer; when it fires, scrolling, coasting and frozen are all cleared and ScrollActivity is told the pane stopped. A drag ending calls coast(), which thaws the rows immediately while leaving everything that rests on a scroll still resting. When the settings view disappears, end() cancels the timer, thaws, and reports the pane stopped exactly once if it had been scrolling.
- **Side effects:** Pauses and resumes frame-driven animations elsewhere in the app through ScrollActivity
- **Persistence:** Nothing.
- **Failure cases:** Window closed mid-scroll: end() reports the stop so no animation stays paused forever.
- **Cancellation:** end() is the cancellation path and is called from onDisappear.
- **Windows path:** One tracker object per settings view instance with the same 150ms debounce, feeding the same app-wide scroll-activity signal used to pause requestAnimationFrame loops.
- **Verify by:** unit test on the tracker's state machine including the 150ms debounce and the end() path
