### PR-COMPOSER-064 - Pasting file URLs attaches them instead of pasting text
- **Source:** DroppyCode/App/Views/Composer/ComposerTextView.swift:163-178 paste - file URLs on the pasteboard are attached as .file sources and the paste ends there; otherwise image data with no string beside it is attached as .image(data, type); otherwise pasteAsPlainText
- **Preconditions:** Focus is in the composer.
- **Action:** The user pastes.
- **Expected:** File references on the clipboard become attachments. Image bytes with no text alongside become one image attachment in the first available of PNG, TIFF, JPEG, HEIC. Anything else pastes as plain text, never as rich text.
- **Side effects:** Copies the pasted files into app storage
- **Persistence:** Attachment files.
- **Failure cases:** Image data plus a text representation: the text wins and is pasted as plain text.
- **Cancellation:** not cancellable
- **Windows path:** Read CF_HDROP for files and CF_DIBV5/PNG clipboard formats for images, in that order, and check for CF_UNICODETEXT before taking the image path.
- **Verify by:** interaction test pasting a file, a screenshot and rich text
