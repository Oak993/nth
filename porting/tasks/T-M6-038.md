## UI contract records

Exact values. Do not round, restyle or substitute. Where a value is macOS-delegated, say so.

- **UI-LAUNCH-004** Dock, application icon / Unread-thread badge on the app icon (badge)
  - text, verbatim: `The decimal count of unread threads, as a plain number with no prefix, suffix or padding; no label at all when the count is zero`
  - geometry: System-drawn dock tile badge; no app-specified geometry
  - type: System-drawn
  - colour: System-drawn
  - states: Zero unread: badgeLabel is nil, so no badge is drawn, not a "0"; One or more unread: the count as a string; Archived threads and threads in a panel never count
  - interactions: Clicking the Dock icon reopens the main window when no window is visible (applicationShouldHandleReopen); Port: Windows has no Dock reopen; the same reopen path runs on a second launch of the single-instance app (engineering_decisions.md ED-002, see PR-LAUNCH-048), and because closing the main window quits the app (OD-0008 C1) the no-visible-window case is not reached by closing it
- **UI-RUNTIME-015** System notification centre and the app's finish chime / Turn-finished notification body and chime (notification)
  - text, verbatim: `Exactly one of: "Finished.", "Stopped.", "Stopped with an error.", or the empty string for a turn still marked running. The notification title is the thread's title.`
  - geometry: Delegated entirely to the OS notification centre.
  - type: Delegated to the OS.
  - colour: Delegated to the OS.
  - states: Suppressed when the thread is visible and the app is active; suppressed when settings.notifyWhenFinished is off; suppressed entirely when the turn continues, when the thread is a Hydra head, and when the thread is waiting on a usage limit. The chime plays when settings.chimeWhenFinished is on and the status is not .interrupted, and a chime that played suppresses the banner's own sound.
  - interactions: Clicking the banner routes back to the thread, outside this area.
