### PR-TERM-059 - Decoding a stored script tolerates a missing id, symbol and worktree flag but requires name and command
- **Source:** DroppyCode/Core/Models/Library.swift:110-117 init(from:) - id defaults to a fresh UUID(), name and command are decoded with try container.decode (required), symbol defaults to "play", runOnWorktreeCreate defaults to false
- **Preconditions:** A stored library contains scripts written by an older version.
- **Action:** The library is decoded.
- **Expected:** A script missing its id gets a fresh one, which means it is a different identity on every load; a script missing symbol becomes "play"; a script missing runOnWorktreeCreate becomes false. A script missing name or command makes the whole decode throw.
- **Persistence:** The regenerated id is written back on the next save.
- **Failure cases:** Missing name or command: the containing decode throws, which is a library-level failure, not a per-script skip.
- **Cancellation:** not cancellable
- **Windows path:** Same tolerances and the same two required fields.
- **Verify by:** unit test over each partial record
