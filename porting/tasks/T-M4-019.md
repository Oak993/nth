### PR-PROVACP-011 - Grok argv, runtime mode .fullAccess reorders the subcommand and drops --permission-mode
- **Source:** DroppyCode/Services/Providers/ACPSession.swift:91 - `case .fullAccess: ["agent", "--always-approve", "stdio"]`

### PR-PROVACP-017 - launchArguments reads the launch-time runtime mode only; a later mode change never relaunches

- **Preconditions:** A session is running and the user changes the runtime mode.
- **Action:** The next turn is sent with a different RuntimeMode.
- **Expected:** The child process is not restarted and its argv is unchanged. Only self.runtimeMode changes, which alters automaticOption's auto-approval policy from the next permission request onward. The CLI-side permission flag chosen at launch stays in force for the life of the process.

- **Cancellation:** not cancellable
- **Windows path:** Same. Do not add a relaunch-on-mode-change path; per port_impacts #23 the ACP launch flags require a process restart and the source does not perform one.
- **Verify by:** interaction test (change mode mid-session, assert no second spawn)

### PR-PROVACP-020 - clientCapabilities declares no filesystem and no terminal capability
- **Source:** DroppyCode/Services/Providers/ACPSession.swift:156-160 - `var capabilities: [String: JSONValue] = ["fs": ["readTextFile": false, "writeTextFile": false], "terminal": false]`
- **Preconditions:** initialize is being built.
- **Action:** clientCapabilities is computed.
- **Expected:** The object is exactly {"fs": {"readTextFile": false, "writeTextFile": false}, "terminal": false} for a non-Cursor provider. All three values are the JSON boolean false, present rather than omitted. The consequence is that the agent never asks Droppy Code to read or write a file or run a terminal, which is why handleRequest rejects every method except session/request_permission (see the handleRequest requirement).
- **Persistence:** None.
- **Cancellation:** not cancellable
- **Windows path:** Identical payload. Do not opt into fs or terminal capabilities on Windows to work around anything; the agent CLI does its own file and process work in the cwd.
- **Verify by:** contract fixture (golden initialize frame)
