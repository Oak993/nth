### PR-PROVACP-002 - One process-launch gate, shared by every ACP session, spaced 1.5 seconds
- **Source:** DroppyCode/Services/Providers/ACPSession.swift:7-21 - `private actor ACPLaunchGate` with `spacing: TimeInterval`, `nextSlot = Date.distantPast`, and `wait()`: `let now = Date.now; let slot = max(now, nextSlot); nextSlot = slot.addingTimeInterval(spacing); if slot > now { try? await Task.sleep(for: .seconds(slot.timeIntervalSince(now))) }` | DroppyCode/Services/Providers/ACPSession.swift:26 - `private static let launchGate = ACPLaunchGate(spacing: 1.5)` | DroppyCode/Services/Providers/ACPSession.swift:110 - `await Self.launchGate.wait()` in start() | DroppyCode/Services/Providers/ACPSession.swift:3-6 - rationale: an agent keeps a store of its own (OpenCode's is SQLite); several starting at once trip over its lock, "database is locked"
- **Preconditions:** configuration.executable is non-nil, so the guard at :109 has passed.
- **Action:** start() awaits the shared launch gate before spawning the child process.
- **Expected:** Spacing is the literal 1.5 seconds. A lone start never waits, because `slot = max(now, nextSlot)` equals now when nextSlot is in the past. A batch of N starts is released one every 1.5 s. The gate is a single static instance shared across every ACPSession of every provider and every thread, so a Cursor start and an OpenCode start issued together are still spaced 1.5 s apart.
- **Side effects:** Delays process spawn by up to (N-1) * 1.5 s for a batch of N.
- **Persistence:** In-memory only: nextSlot lives for the life of the app process.
- **Failure cases:** `try? await Task.sleep` swallows the sleep's error; the wait then returns early and the start proceeds.
- **Cancellation:** The sleep's thrown error is discarded by `try?`, so cancelling the awaiting task does not abort the start at this point.
- **Windows path:** A single module-level async mutex holding nextSlot, awaited in the Electron main process before child_process.spawn. It must be one instance for the whole app, not per session, per window or per provider.
- **Verify by:** unit (fake clock: the Nth start releases at (N-1)*1500 ms, a single start at 0 ms)
