### PR-COMPOSER-078 - The Downloads popover lists the 15 most recently modified non-directory files in the Downloads folder, each sized with ByteCountFormatStyle
- **Source:** DroppyCode/App/Views/Composer/DownloadsPopover.swift:18-19 limit = 15, previewPointSize = 30 | DroppyCode/App/Views/Composer/DownloadsPopover.swift:33-90 load - contentsOfDirectory with skipsHiddenFiles; directories dropped; sorted by content modification date descending; the first 15 kept; an image extension gets a square-filling thumbnail at point size 30; items and isLoaded are published before the thumbnails arrive | DroppyCode/App/Views/Composer/DownloadsPopover.swift:68 - `size: size > 0 ? Int64(size).formatted(.byteCount(style: .file)) : nil` | DroppyCode/App/Views/Composer/DownloadsPopover.swift:29-31 imageExtensions = png, jpg, jpeg, heic, heif, gif, tiff, tif, bmp, webp
- **Preconditions:** The popover opens.
- **Action:** The folder is read.
- **Expected:** Up to 15 files, newest first by modification date, hidden files and directories excluded. Each row shows a thumbnail for the ten listed image extensions and the system file icon otherwise, the file name, and the formatted size when it is above zero (a zero-byte file shows no size text at all, since the ternary's false branch is nil, not a formatted zero). The size string is Foundation's ByteCountFormatStyle(.file): whole kB/MB have no decimal, MB shows up to one decimal, GB and above up to two, half-even rounded; the unit switches from bytes to kB at 999 bytes; unit words are lowercase "kB", "MB", "GB". Rows appear as soon as the listing lands; thumbnails fill in afterwards.
- **Side effects:** Reads the Downloads directory and decodes thumbnails
- **Persistence:** Nothing persisted.
- **Failure cases:** No Downloads directory: load returns and the popover stays in its loading state.; A directory read that throws yields an empty list, which shows the empty note.
- **Cancellation:** The scan is cancelled with the task, and cancellation is propagated to the detached scan.
- **Windows path:** SHGetKnownFolderPath(FOLDERID_Downloads). Same limit, sort, extension set and thumbnail size. The size text needs the same ported ByteCountFormatStyle helper as PR-COMPOSER-076 (6.1 E2), not the existing ByteCountFormatter-shaped FileByteCount helper, whose "KB" (uppercase) and 1000-byte threshold no longer match this site.
- **Verify by:** interaction test against a fixture Downloads folder, plus exact-string size assertions shared with PR-COMPOSER-076's table
