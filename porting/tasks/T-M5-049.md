- **Preconditions:** The link popover is open.
- **Action:** The user reads it and chooses a row.
- **Expected:** The popover is 220 points wide with 6 points of padding, its rows stacked leading-aligned with no spacing between them. Every link shows a row labelled exactly "Open Link" with a compass symbol and a row labelled exactly "Copy Link" with a link symbol. A merge or pull request link, in a chat that can merge, shows first a row whose text is the word "Merge" in semibold followed by the request's own label, wearing the forge host's favicon (or a merge-arrow symbol until the icon loads), then a divider. Open Link opens the URL in the default browser. Copy Link clears the clipboard and writes the URL's absolute string as plain text. Merge closes the popover and hands the request to the chat.
- **Side effects:** Open Link launches the browser; Copy Link writes the clipboard; Merge closes the popover and starts a merge in the chat; The Merge row may fetch a favicon
- **Persistence:** not persisted
- **Failure cases:** Content that measures to a non-positive size falls back to 220 by 110 points.
- **Cancellation:** Dismissing the popover cancels nothing that has started.
- **Windows path:** The three row labels are verbatim. The merge behaviour itself belongs to the GIT and HYDRAMERGE areas; this requirement fixes the popover's shape, its labels and its two universal actions.
- **Verify by:** interaction test: the row set with and without a merge target; unit: the three exact labels
