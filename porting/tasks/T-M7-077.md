### PR-COMPOSER-016 - The composer's growth animates with a 0.28 second smooth curve, suppressed while the window is being resized
- **Source:** DroppyCode/App/Views/Composer/ComposerView.swift:604 .animation(liveResize.isReshaping ? nil : .smooth(duration: 0.28), value: composerHeight)
- **Preconditions:** The composer height changes.
- **Action:** A line is added or removed, or the window is dragged so the text rewraps.
- **Expected:** Normally the clip's height animates over 0.28 seconds with a smooth curve. While the window is being reshaped the height follows the rewrap immediately with no animation, because a spring restarted per frame lagged behind the window.
- **Persistence:** Nothing persisted.
- **Cancellation:** not cancellable
- **Windows path:** Needs a live-resize signal equivalent to WindowLiveResize; on Windows that is the modal resize loop (WM_ENTERSIZEMOVE/WM_EXITSIZEMOVE).
- **Verify by:** interaction test resizing the window with a wrapped draft
