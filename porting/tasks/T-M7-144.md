### PR-MCP-207 - The custom editor builds its draft by trimming keys, dropping empty-key rows, and keeping the variable list across a kind switch
- **Source:** DroppyCode/App/Views/Settings/MCPSettingsPage.swift:822-839 the draft computed property
- **Preconditions:** The editor is open.
- **Action:** The header icon renders, or Save is pressed.
- **Expected:** Variables become the kept list: each key trimmed of whitespace and rows whose key is then empty dropped, so a half-typed row never fails validation. The draft's id is the edited server's id, else the id from an earlier successful save in this editor session, else makeID of the current name. command and url are trimmed of whitespace and newlines. args are the argument text split on newline with every line that is blank after trimming dropped - and the surviving lines are NOT trimmed, so a leading dash, an embedded quote or a trailing space reaches the server exactly as typed. The kept variables go to env for stdio and to headers for http, so switching kind carries the typed rows across.
- **Side effects:** none
- **Persistence:** none until Save
- **Failure cases:** none
- **Cancellation:** closing the popover discards the draft entirely
- **Windows path:** Same trimming rules and especially the untrimmed argument lines: trimming them would silently change command lines.
- **Verify by:** unit over the argument splitting with a line that has a trailing space
