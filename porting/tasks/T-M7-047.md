### PR-CHAT-031 - Agent-kind tool calls never join a work run; they collect into one trailing heads group

- **Preconditions:** A run contains one or more agent tool calls.
- **Action:** Grouping runs.
- **Expected:** Every agent call is pulled out of the stream in order and appended as a single .heads group at the very end of the group list, with id "heads-" plus the first head entry's id. - **Persistence:** None.
- **Cancellation:** not cancellable
- **Windows path:** Same extraction and same trailing placement; the heads list stays in view under the turn's response whether the steps are folded or not.
