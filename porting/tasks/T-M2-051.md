- **Preconditions:** The shortcut store has no override for this command.
- **Action:** The command's chord is looked up, for a menu item, for a help label, or for the palette's shortcut column.
- **Expected:** The chord is Option-Command-U. The command's title in the shortcut settings list is exactly "Activity view" and its help line is exactly "Lists every thread by when it was last active.". It appears in the Window and panels section. Any override the user records is stored under the exact key "toggleActivityView".
- **Persistence:** An override for this command is stored in the "keyboardShortcuts" blob under the key "toggleActivityView". No entry means the default above applies; an entry whose chord is null means the command has been deliberately cleared and answers to no chord at all.
- **Cancellation:** not cancellable
- **Windows path:** Virtual-key VK_U with the same modifier set, Command mapping to Ctrl. The macOS key code 32 is a US key POSITION, not a character, so the Windows equivalent is the virtual-key code for the same position. The persisted macOS blob is unreadable on Windows: the port defines its own chord format and starts from these defaults (port_impacts.md entry 110, CC1).
- **Verify by:** contract fixture over all nineteen commands: case, stored key, title, detail, section and default chord
