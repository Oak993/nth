### PR-CHAT-001 - TimelineItem is the single persisted unit of a conversation, with id, optional turnID, date and a tagged content union
- **Source:** DroppyCode/Core/Models/Timeline.swift:4-15 struct TimelineItem - Codable, Identifiable, Hashable, Sendable; fields id: String, turnID: UUID?, date: Date, content: Content; init defaults id = UUID().uuidString and date = .now | DroppyCode/Core/Models/Timeline.swift:17-26 enum Content - the eight cases the timeline can hold
- **Preconditions:** A thread document is being built in memory or decoded from disk.
- **Action:** The runtime appends or decodes a timeline item.
- **Expected:** Every item carries exactly four stored fields: id (String, defaulting to a fresh UUID string), turnID (UUID or null), date (Date, defaulting to now) and content, which is exactly one of user, assistant, reasoning, tool, plan, todos, notice, turnEnd. No other case exists and no other field is stored.
- **Persistence:** Serialized inside ThreadDocument.items under the JSON keys id, turnID, date, content; the content union is encoded by Swift's synthesized enum coding, i.e. a single-key object whose key is the case name.
- **Failure cases:** An item that fails to decode is dropped rather than failing the whole document (see PR-CHAT-019).
- **Cancellation:** not cancellable
- **Windows path:** A discriminated-union record type in the Windows model layer, serialized with the same key names and the same single-key-object shape for the union, so a thread written by either build round-trips.
- **Verify by:** contract fixture: encode/decode round-trip against a pinned JSON fixture per content case

### PR-CHAT-002 - A reasoning block whose text is only whitespace is flagged empty
- **Source:** DroppyCode/Core/Models/Timeline.swift:28-32 TimelineItem.isEmptyReasoning - guard case .reasoning(let block); returns `block.text.trimmed.isEmpty`, where DroppyCode/Core/Support/Text.swift:132 is `var trimmed: String { trimmingCharacters(in: .whitespacesAndNewlines) }`
- **Preconditions:** A timeline item exists.
- **Action:** Anything asks the item whether it is empty reasoning.
- **Expected:** True only when the content is .reasoning and its text trims to the empty string over the Unicode whitespace-and-newlines set. Every other content case returns false, including an assistant message with empty text.
- **Persistence:** Derived, never persisted.
- **Cancellation:** not cancellable
- **Windows path:** Trim against the same Unicode whitespace and newline set (not ASCII-only), because a redacted reasoning stream can leave non-breaking or line-separator characters behind.
- **Verify by:** unit

### PR-CHAT-004 - UserMessage carries text, attachments and two optional Hydra markers that decide which row draws it

- **Preconditions:** A user-kind timeline item is about to be rendered.

- **Verify by:** unit plus interaction test over the three branches

### PR-CHAT-005 - Attachment identifies a file by path and mime type, is an image when the mime type starts with image/, and hands providers base64 images that are downscaled past 2000 pixels
- **Source:** DroppyCode/Core/Models/Timeline.swift:89-97 struct Attachment - id = UUID(), name, path, mimeType; url is URL(fileURLWithPath: path); isImage is mimeType.hasPrefix("image/") | DroppyCode/Core/Models/Timeline.swift:102-111 Attachment.base64Images - `@concurrent`; compactMap over attachments; `guard attachment.isImage, let data = try? - **Preconditions:** A message carries attachments.
- **Action:** The UI or the provider path asks whether an attachment is an image, or asks for the base64 images.
- **Expected:** isImage is a literal prefix test on the mimeType string against "image/", never on the file extension. base64Images reads each image's bytes off the main actor and silently skips any attachment whose bytes cannot be read, returning only the pairs that succeeded, in the original order. For each image it tries downscaledJPEG (PR-CHAT-190): when that returns data, the pair carries that JPEG's base64 and a copy of the attachment whose mimeType is "image/jpeg"; otherwise it carries the original bytes' base64 and the attachment unchanged. The stored attachment is never modified; only the returned copy changes.
- **Side effects:** base64Images reads each image file from disk; An image more than 2000 pixels on its longest side is decoded and re-encoded as a JPEG in memory

- **Failure cases:** A file that cannot be read is dropped from the result with no error and no notice.; An image ImageIO cannot read, or whose JPEG encoding fails, is sent with its original bytes and mime type, with no error and no notice.
- **Cancellation:** not cancellable
- **Windows path:** URL(fileURLWithPath:) becomes a Windows absolute path; the stored path is the platform path as captured. - **Verify by:** unit with a fixture directory holding one unreadable path, one image at most 2000 pixels on its longest side and one larger image, asserting order, skipped entries, returned bytes and returned mime types

### PR-CHAT-007 - Tool output is trimmed to a 60000-byte ceiling by replacing the head with a single ellipsis and keeping the last 30000 bytes
- **Source:** DroppyCode/Core/Models/Timeline.swift:169 static let outputLimit = 60_000 | DroppyCode/Core/Models/Timeline.swift:181-189 appendOutput appends then trims; setOutput replaces then trims | DroppyCode/Core/Models/Timeline.swift:196-199 trimOutput - guard output.utf8.count > Self.outputLimit; output = "…" + String(output.suffix(Self.outputLimit / 2))
- **Preconditions:** A tool call is streaming or has just received its whole output.
- **Action:** appendOutput or setOutput is called.
- **Expected:** While the output's UTF-8 byte count is at most 60000 it is kept whole. Above that the output becomes the single character U+2026 HORIZONTAL ELLIPSIS followed by the last 30000 Characters of the current output. Note that the guard counts UTF-8 bytes while suffix counts Characters, so the trimmed result can still exceed 60000 bytes for non-ASCII output; this is the shipped behavior.
- **Persistence:** The trimmed value is what is stored in the item and written to disk.
- **Cancellation:** not cancellable
- **Windows path:** Reproduce the byte-count guard and the Character-count suffix exactly, including the unit mismatch. Windows string indices are UTF-16 code units: suffix must be taken over grapheme clusters, not code units, or a surrogate pair is split.
- **Verify by:** unit with an ASCII case, a CJK case and an emoji case at the boundary

### PR-CHAT-008 - finish() sets the status and stamps finishedAt only the first time

- **Cancellation:** not cancellable
- **Windows path:** Same first-write-wins rule on finishedAt.
- **Verify by:** unit
