### PR-RUNTIME-049 - apiTranscript keeps the last 40 messages and trims them to a 60000-character budget from the end
- **Source:** DroppyCode/App/Runtime/ThreadRuntime.swift:1636-1650 - var kept = Array(transcript.suffix(40)); var budget = 60_000; for index in kept.indices.reversed() { let length = kept[index].text.count; if length <= budget { budget -= length } else if budget > 200 { kept[index].text = "…" + String(kept[index].text.suffix(budget)); budget = 0 } else { kept.removeSubrange(...index); break } }
- **Preconditions:** The transcript has been assembled.
- **Action:** The bounding pass runs.
- **Expected:** At most 40 messages survive the suffix. Walking from the newest backwards, a message that fits spends its length from the budget; the first message that does not fit is truncated to a suffix of exactly the remaining budget with a single U+2026 HORIZONTAL ELLIPSIS prepended, but only when more than 200 characters remain, and the budget then drops to zero; otherwise that message and every older one are removed and the walk stops. Lengths are counted in Swift characters, not bytes.
- **Persistence:** Not persisted.
- **Cancellation:** not cancellable
- **Windows path:** Count in Unicode grapheme clusters if the platform offers them, otherwise in code points, and record the choice: counting UTF-16 units would trim differently on a history with emoji.
- **Verify by:** unit - boundary fixtures at 40 messages, at exactly 60000 characters and at the 200-character floor
