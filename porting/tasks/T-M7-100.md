## Requirements

### PR-COMPOSER-174 - The follow-up editor offers Cancel and Save, with Save disabled while the edit is empty
- **Source:** DroppyCode/App/Views/Composer/FollowUpEditor.swift:10-24 PromptEditor(title: "Edit follow-up", ...) with Button("Cancel", role: .cancel) in .glass and Button("Save") in .glassProminent, disabled while edit.isEmpty | DroppyCode/App/Views/Composer/FollowUpEditor.swift:27-35 save - guard !edit.isEmpty; runtime.updateFollowUp(id, text:attachments:); followUpEdit = nil; cancel just clears followUpEdit
- **Preconditions:** The editor is open.
- **Action:** The user presses Save or Cancel.
- **Expected:** The editor's title is exactly "Edit follow-up". Save writes the text and attachments back to the queued prompt and closes; it is disabled while the edit holds no attachment and no non-whitespace text. Cancel discards the edit and closes.
- **Persistence:** The queue is saved on Save.
- **Cancellation:** Cancel discards.
- **Windows path:** Verbatim labels; Cancel carries the cancel role, so Escape maps to it.
- **Verify by:** interaction test saving and cancelling
