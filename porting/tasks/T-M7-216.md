## UI contract records

Exact values. Do not round, restyle or substitute. Where a value is macOS-delegated, say so.

- **UI-TERM-001** Chat column, terminal drawer / Terminal drawer panel (the whole sheet rising from the bottom of the chat column) (panel)
  - geometry: Full pane width. Height = dragHeight ?? settings.terminalHeight (default 260, applied unclamped; drag clamps 140...760). Background UnevenRoundedRectangle with topLeadingRadius 16, topTrailingRadius 16, style .continuous, square bottom corners. Internal layout VStack(spacing: 0): a 38-point tab row then the terminal or the empty state.
  - type: n/a
  - colour: Fill Color(white: 0.08) in dark, Color(white: 0.985) in light. Literal greys, not theme tokens; identical to the terminal view's own background so there is no seam.
  - states: visible: mounted with a move-from-bottom plus opacity transition under Chrome.panelSlide; hidden: unmounted; shells keep running; resizing: height follows the pointer and the chat pane is flagged as live-resizing; thread switching: the visibility animation is nil, so the change is instant; empty: the tab strip is empty and the body shows the empty state
  - interactions: drag the 8-point top strip to resize; Escape while the composer has focus hides it (after a running turn, before the changes panel); Escape inside the terminal at the shell prompt hides it; Command-J, the chrome Terminal button, the View menu item and the palette action all toggle it
- **UI-TERM-002** Terminal drawer, tab row / Tab strip scroll area (list)
  - geometry: ScrollView(.horizontal, showsIndicators: false) wrapping HStack(spacing: 4); .fixedSize(horizontal: false, vertical: true). Sits inside the 38-point row, which has .padding(.horizontal, 10) and HStack(spacing: 6) between its groups.
  - type: n/a (tabs carry their own)
  - colour: No background of its own.
  - states: overflowing: scrolls horizontally with no visible scrollbar; empty: zero width, so the plus button sits at the left edge
  - interactions: horizontal scroll or sideways drag scrolls the tabs and does NOT resize the drawer
- **UI-TERM-003** Terminal drawer, tab row / Terminal tab chip (row)
  - text, verbatim: `<session title>, which is "Terminal N" for a plain tab or the script's name for a script tab`
  - geometry: HStack(spacing: 6); .padding(.horizontal, 10); .padding(.vertical, 5); capsule background and capsule content shape; 4 points from its neighbours.
  - type: .font(.callout) for the chip; the terminal glyph at .caption; the restart and close glyphs at .caption2.weight(.bold).
  - colour: Selected: foregroundStyle .primary over .primary.opacity(0.08) in a capsule. Unselected: foregroundStyle .secondary over Color.clear.
  - states: selected: primary text on the 8 percent capsule, plus the close cross visible and clickable; hovered: the close cross becomes visible and clickable; exited shell: whole chip at opacity 0.55, restart button present, tooltip and accessibility label gain the exited wording; running: opacity 1, no restart button
  - interactions: click anywhere on the capsule to select; hover to reveal the close cross
- **UI-TERM-004** Terminal drawer, tab row / Tab terminal glyph (icon)
  - geometry: Leading item of the tab HStack, 6 points before the title.
  - type: .font(.caption)
  - colour: Inherits the chip's foreground style (.primary when selected, .secondary otherwise), and the chip's 0.55 opacity when the shell has exited.
  - states: no state of its own
  - interactions: none; clicks fall through to the chip
- **UI-TERM-005** Terminal drawer, tab row / Tab title label (label)
  - text, verbatim: `<session title>`
  - geometry: Between the glyph and the buttons, 6 points from each.
  - type: Inherits .font(.callout) from the chip.
  - colour: Inherits the chip's foreground style.
  - states: long title: .lineLimit(1) truncates rather than wrapping or growing
  - interactions: none; clicks fall through to the chip
- **UI-TERM-006** Terminal drawer, tab row / Restart button on an exited tab (button)
  - geometry: Between the title and the close cross, 6 points from each. Present only when the shell has exited, so the chip is narrower while the shell runs.
  - type: .font(.caption2.weight(.bold))
  - colour: .foregroundStyle(.secondary), under the chip's 0.55 exited opacity.
  - states: only present when !session.isRunning
  - interactions: click: terminates the old session and puts a fresh shell in the same tab position, keeping the title and directory and dropping any startup command
- **UI-TERM-007** Terminal drawer, tab row / Close cross on a tab (button)
  - geometry: Trailing item of the tab HStack, 6 points after the title or the restart button. Always occupies its slot, so the chip width does not change on hover.
  - type: .font(.caption2.weight(.bold))
  - colour: .foregroundStyle(.secondary).
  - states: hidden: opacity 0 and allowsHitTesting false when the tab is neither hovered nor selected, so a click there selects the tab instead; shown: opacity 1 and clickable when hovered or selected
  - interactions: click: terminates the shell and removes the tab; if it was selected, the selection moves to the LAST remaining tab
- **UI-TERM-008** Terminal drawer, tab row / New terminal button (button)
  - geometry: After the tab strip, 6 points from it. Chip button style: .padding(.horizontal, 9), .padding(.vertical, 5), capsule background and content shape.
  - type: Glyph at Chrome.iconFont = .system(size: 12, weight: .semibold); the chip style itself sets .font(.callout) on the label.
  - colour: Chip style, not active: foreground .secondary; fill .primary.opacity(0) at rest, .primary.opacity(0.07) on hover, .primary.opacity(0.12) while pressed, animated with .easeOut(duration: 0.12).
  - states: rest: no fill; hover: 7 percent primary fill; pressed: 12 percent primary fill
  - interactions: click: opens a new session in the thread's directory named "Terminal N" and selects it
- **UI-TERM-009** Terminal drawer, tab row / Hide terminal button (button)
  - geometry: At the trailing edge of the row after a Spacer(minLength: 0). Chip button style, same metrics as the plus button.
  - type: Glyph at Chrome.iconFont = .system(size: 12, weight: .semibold).
  - colour: Chip style, not active, same three fills as UI-TERM-008.
  - states: rest, hover, pressed as the chip style defines
  - interactions: click: sets runtime.isTerminalVisible = false; shells keep running
- **UI-TERM-010** Terminal drawer, body / Hosted terminal view (terminal)
  - geometry: Fills the area below the 38-point tab row, inset .leading 12, .trailing 6, .bottom 6, no extra top inset. The underlying view is created at NSRect(0, 0, 640, 240) and immediately resized to the container.
  - type: NSFont.monospacedSystemFont(ofSize: 12, weight: .regular)
  - colour: Dark: background white 0.08, foreground white 0.9. Light: background white 0.985, foreground white 0.12. Caret = Chrome.accentNSColor (theme accent, or the system control accent for System, Light and Dark). Selection background = that accent at 0.3 alpha. The 16 ANSI colours are SwiftTerm 1.20.0 defaults and are not configured anywhere in the source.
  - states: focused: takes the keyboard once when the drawer is opened; exited: keeps showing its final scrollback; the tab dims; window live-resizing: autoresizing parked, frame synced at most every 50 ms, one final sync on release
  - interactions: all keyboard input goes to the shell; Option is sent as Meta (optionAsMetaKey = true); Escape at the shell prompt with no modifiers closes the drawer and is swallowed; Escape with a foreground program running reaches that program; mouse selection uses SwiftTerm's own handling
