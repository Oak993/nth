## The probe, verbatim from the stack decision

P11 - Packaging and update smoke test. dotnet publish -r win-x64 self-contained; dotnet tool install -g vpk and vpk pack; then a single unauthenticated GET to the public GitLab Releases API with an all-or-nothing lenient six-field decode. PASS: the installer installs and launches on this machine as an ordinary desktop app with no dev server, no WSL and no browser tab; and the check emits PR-UPDATE-019/020/027's literal strings byte-for-byte on both the success and the unreachable paths, including the U+2019 apostrophe in "Couldn't reach GitLab.". Installer signature verification is written against WinVerifyTrust / X509Certificate2 but stays untestable end to end until UNK-0009 (no Windows release asset, no certificate) is closed - that is a project gap, not a stack gap. Every step here runs with the .NET SDK 10.0.401 already installed; no MSVC, no cmake, no Rust.

## Rules

- Read `WORKER_BRIEF.md` first. Model the probe on `porting/probes/p1-glass/`, which passed.
- A probe PROVES or DISPROVES one capability. Report the measured result, whichever it is.
  A FAIL reported honestly is a valuable result. A PASS you did not measure is worthless.
- Build a control case that must fail when the thing under test is absent, as P1 did with
  its tint-only render. Without one, a PASS cannot be trusted.
- Never send a prompt to a real AI CLI; `--version` or `--help` only.
- Set `MARROW_PORT_DATA_DIR` to a throwaway folder before running anything.
