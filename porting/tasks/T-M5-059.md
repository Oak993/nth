### PR-THEME-139 - The favicon cache discards every icon at 300 entries and never clears its failure set
- **Source:** DroppyCode/UI/Markdown/MarkdownView.swift:896-901 `if let image { if memory.count >= 300 { memory.removeAll(keepingCapacity: true) }; memory[key] = image } else { failed.insert(key) }` | DroppyCode/UI/Markdown/MarkdownView.swift:873-876 the failed set and the in-flight map | E:/Droppy/port/porting/upstream_defects.md entry 49 | E:/Droppy/port/porting/extracts/markdown-link-grammar.md gotcha 10
- **Preconditions:** 300 or more favicons are cached.
- **Action:** One more icon is stored.
- **Expected:** Every cached icon is discarded in one go and the new one becomes the only entry, so every favicon in a long thread blanks and is re-fetched at once. The failure set is never cleared, so a host that failed once has no icon for the rest of the session even after a network problem clears.
- **Side effects:** A burst of re-fetches after the flush
- **Persistence:** not persisted
- **Failure cases:** Observable as every icon in a thread disappearing and reappearing together.
- **Cancellation:** not cancellable
- **Windows path:** Reproduce as a wholesale flush, not an LRU eviction: the 301st favicon really does drop all 300 (port_impacts.md entry 152).
- **Verify by:** unit: the 301st store empties the map; a failed host is not retried
- **Upstream defect 49: reproduce it faithfully, do not fix it.**

### PR-THEME-151 - A native paragraph publishes first and last baseline guides measured once per point size, so list markers align with its text
- **Source:** DroppyCode/UI/Markdown/MarkdownView.swift:1098-1105 the comment: an AppKit view has no text baseline of its own, so a list marker sat on the paragraph's top edge; the first line's baseline is the base font's ascender from the top and the last is one line up from the bottom | DroppyCode/UI/Markdown/MarkdownView.swift:1116-1117 `.alignmentGuide(.firstTextBaseline) { _ in ascender }` and `.alignmentGuide(.lastTextBaseline) { $0.height - lineHeight + ascender }` | DroppyCode/UI/Markdown/MarkdownView.swift:1137-1148 metrics(pointSize:): the ceiling of the system font's ascender, and the ceiling of ascender minus descender plus leading, cached per point size | DroppyCode/UI/Markdown/MarkdownView.swift:1094 `let scaled = (pointSize * 2).rounded() / 2`, so sizes land on half points
- **Preconditions:** A link paragraph is inside a list item or another baseline-aligned stack.
- **Action:** The stack lays out.
- **Expected:** The paragraph reports its first text baseline as the base font's ascender, rounded up, measured from its top, and its last text baseline as its height minus one line height plus that ascender. Line height is the ascender minus the descender plus the leading, rounded up. Both numbers are measured once per point size and reused. - **Persistence:** not persisted
- **Failure cases:** None expressed in source.
- **Cancellation:** not cancellable

- **Verify by:** capture comparison: a list item whose text is a link paragraph aligns its dot with the first line
