## Requirements

### PR-MCP-041 - resolve() of a stdio entry fills args and env and drops env variables whose value resolved empty
- **Source:** DroppyCode/Services/MCP/MCPCatalogEntry+Resolve.swift:7-24 resolve(values:), the .stdio case at :11-15
- **Preconditions:** A catalog or custom entry with .stdio transport.
- **Action:** The store resolves the entry for a probe, a provider config export or the proxy.
- **Expected:** MCPResolvedServer gets id and name from the entry, command set to the transport's command verbatim (never filled), args = the transport args each passed through fill, env = the entry's env map with each value filled and then filtered to drop every pair whose filled value is the empty string. url, headers and oauthUpstream stay nil/empty, so isRemote is false. The env key is never filled - only values are.
- **Side effects:** none
- **Persistence:** none directly; the result is what writeAll serializes into the four provider config files
- **Failure cases:** an optional secret left blank drops its whole environment variable rather than passing an empty string
- **Cancellation:** not cancellable
- **Windows path:** Same. The command string is not path-resolved here; resolution to an executable happens in the probe and the hub.
- **Verify by:** unit with an optional field left blank

### PR-MCP-042 - resolve() of an http entry fills the URL and headers and drops headers whose value resolved empty
- **Source:** DroppyCode/Services/MCP/MCPCatalogEntry+Resolve.swift:16-18 the .http case of resolve
- **Preconditions:** A catalog or custom entry with .http transport.
- **Action:** The store resolves the entry.
- **Expected:** url = fill(transport url), headers = transport headers with each value filled then filtered for non-empty values. command, args, env and oauthUpstream stay nil/empty, so isRemote is true. Note "Bearer {key}" with an empty key resolves to the non-empty string "Bearer " and is therefore kept, not dropped.
- **Side effects:** none
- **Persistence:** the resolved url and headers are written into claude.json, codex.json, copilot.json and gemini-settings.json
- **Failure cases:** a header whose entire value is a bare placeholder resolving empty is dropped
- **Cancellation:** not cancellable
- **Windows path:** Same, including the "Bearer " edge case for context7 and huggingface with no key.
- **Verify by:** unit asserting "Bearer " survives the filter
