### PR-PROVCLI-204 - Command Code holds no long-lived process: a session is a conversation and each turn spawns the CLI anew
- **Source:** DroppyCode/Services/Providers/CommandCodeSession.swift:5-9 - the header: no long-lived server protocol; each turn is one `cmd -p` process | DroppyCode/Services/Providers/CommandCodeSession.swift:90-92 - the doc comment plus var isRunning { started && !stopped }
- **Preconditions:** A Command Code thread.
- **Action:** start() and then send() are called.
- **Expected:** start() spawns NOTHING. isRunning is purely the pair of flags started and !stopped, not any process state - contrast Claude, which asks its process, and Codex and Copilot, which ask their connections. Each send() spawns one `cmd -p` process that lives for exactly one turn and then exits.
- **Side effects:** One child process per turn
- **Persistence:** The CLI persists each finished turn to its own transcript.
- **Failure cases:** none
- **Cancellation:** stop() sets stopped, which makes isRunning false even though no process exists.
- **Windows path:** One process per turn means the Windows process-creation cost and any anti-malware scan cost is paid on every message, not once per thread. Each process must still be placed in a Job Object so a tool it spawned cannot outlive it (PA-0007).
- **Verify by:** interaction test asserting no process exists between turns

### PR-PROVCLI-206 - Command Code finds a transcript by scanning every project folder for <sessionId>.jsonl
- **Source:** DroppyCode/Services/Providers/CommandCodeSession.swift:115-124 - transcriptExists with its doc comment: home from environment["HOME"] when non-empty else LoginEnvironment.homeDirectory; <home>/.commandcode/projects; contentsOfDirectory; any folder containing "<sessionID>.jsonl"
- **Preconditions:** A session id.
- **Action:** transcriptExists runs.
- **Expected:** The home directory is environment["HOME"] when it is present and non-empty, otherwise LoginEnvironment.homeDirectory. The projects directory is that home joined with the literal segment ".commandcode/projects". Listing it is attempted; a failure returns false. The result is true when ANY immediate child folder contains a file named exactly "<sessionID>.jsonl". This is a directory SCAN, unlike Pi, whose session id is itself a file path and is checked directly.
- **Side effects:** A directory listing and up to one existence check per project folder
- **Persistence:** none
- **Failure cases:** An unreadable or absent projects directory returns false, which start() turns into the message in PR-PROVCLI-205.
- **Cancellation:** not cancellable
- **Windows path:** HOME is normally unset on Windows, so LoginEnvironment.homeDirectory is the real source and must resolve to the user profile. The path segment ".commandcode/projects" uses a forward slash; it must be joined as path components, not concatenated. The scan cost grows with the number of projects and runs on every session start.
- **Verify by:** unit test against a fixture tree with and without the transcript
