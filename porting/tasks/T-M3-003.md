### PR-GIT-001 - Every git process is spawned with the four-element invariant prefix before the caller's arguments
- **Source:** DroppyCode/Services/Git/Git.swift:30-49 Git.run(_:environment:input:timeout:) - builds argv as ["-c", "core.quotepath=false", "-c", "color.ui=false"] + arguments and passes it to Shell.run with in: directory | DroppyCode/Services/Git/Git.swift:28 Git.executable - private static var executable: URL { LoginEnvironment.git } | porting/extracts/git-command-vectors.md section 1 - 'Four prefix elements in that order, always, with no conditional inclusion.'
- **Preconditions:** A Git value has been constructed with a directory path.
- **Action:** Any Git method runs a git subcommand.
- **Expected:** The spawned process is <resolved git executable> with argv exactly ["-c", "core.quotepath=false", "-c", "color.ui=false"] followed by the caller's argument array, in that order, with no conditional inclusion and no other global options. The working directory is the Git value's own directory, never the repository root.
- **Side effects:** One child process per invocation
- **Persistence:** None.
- **Failure cases:** Spawn failure propagates as a thrown error from Shell.run, not as a ShellResult
- **Cancellation:** Not cancellable at this layer; the timeout path (PR-GIT-004) is the only interruption.
- **Windows path:** Spawn git.exe with shell:false and an explicit argv array. Platform boundary: CreateProcess argument quoting. %(refname), --batch-check=%(objecttype), ^{tree} and refs/heads/x:refs/heads/x must never pass through cmd.exe or PowerShell, where % expands and ^ escapes.
- **Verify by:** contract fixture: a recording git shim asserts the exact argv of every invocation

### PR-GIT-010 - status() parses status --porcelain=v2 --branch into branch, upstream, ahead, behind and changedFiles
- **Source:** DroppyCode/Services/Git/Git.swift:80-98 status() - run(["status", "--porcelain=v2", "--branch"]) and the three prefix literals | DroppyCode/Services/Git/Git.swift:824-827 Substring.value(after:) - the prefix matcher | DroppyCode/Services/Git/Git.swift:4-10 GitStatus - branch, upstream, ahead = 0, behind = 0, changedFiles = 0
- **Preconditions:** The directory is a git checkout.
- **Action:** The chrome refreshes its git status.
- **Expected:** argv ["status", "--porcelain=v2", "--branch"] at 120 s. Output is split on "\n". A line beginning with the literal "# branch.head " (trailing space included) sets branch to the remainder, except the exact value "(detached)" which sets branch to nil. "# branch.upstream " sets upstream to the remainder. "# branch.ab " is split on " " and each token starting "+" sets ahead and each starting "-" sets behind, both via integer parse of the remainder defaulting to 0. Every line not starting with "#" increments changedFiles by one. A thrown error or non-zero exit yields nil for the whole status.
- **Side effects:** One git process
- **Persistence:** None.
- **Failure cases:** Failure yields nil, and the branch menu then shows "Detached"
- **Cancellation:** not cancellable
- **Windows path:** Direct port. Decode stdout as UTF-8 with no CRLF translation; split on \n only.
- **Verify by:** unit over recorded porcelain v2 fixtures, detached and with ahead/behind
