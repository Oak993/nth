### PR-PROVACP-102 - Ending a turn clears the todo routing set and cancels every still-open permission
- **Source:** DroppyCode/Services/Providers/ACPSession.swift:607-612 - `todoToolCallIDs.removeAll(); for (key, id) in pendingPermissions { connection?.respond(to: id, result: ["outcome": ["outcome": "cancelled"]]); onEvent?(.requestResolved(id: key)) }; pendingPermissions.removeAll()`
- **Preconditions:** A turn is ending for any reason.
- **Action:** finishPrompt runs.
- **Expected:** todoToolCallIDs is emptied, so the next turn re-detects todo calls from scratch and a tool id reused across turns is not wrongly routed to the checklist. Every still-open approval is answered {"outcome": {"outcome": "cancelled"}} and its card dismissed with .requestResolved, so no approval card outlives its turn. This runs on success, failure and interruption alike.
- **Side effects:** One response frame and one event per open approval.
- **Persistence:** None.
- **Failure cases:** When the connection has already closed, respond is a no-op on a closed connection (JSONRPC.swift:106) but .requestResolved is still emitted, so cards are dismissed either way.
- **Cancellation:** This is part of the cancellation path.
- **Windows path:** Same.
- **Verify by:** interaction test (open approval, let the turn fail, assert the card is gone)

### PR-PROVACP-107 - A process close during a turn fails that turn with the last lines of stderr

- **Preconditions:** The child's message stream finished while a turn was in flight.
- **Action:** handleClose runs.
- **Expected:** The turn is completed as .failed with the last FOUR non-empty, ANSI-stripped, trimmed lines of the process's stderr tail, joined by newlines. When the tail has no non-empty lines the message is exactly "The agent exited." - capital T, trailing full stop.
