### PR-PROVCLI-352 - A Codex skill turn rewrites the leading slash into a dollar sign
- **Source:** DroppyCode/Core/Models/Provider.swift:330 - ["type": "text", "text": .string("$" + text.dropFirst())]
- **Preconditions:** Both conditions of PR-PROVCLI-351 held.
- **Action:** The first part is built.
- **Expected:** The first part is {"type":"text","text":<rewritten text>} where the rewritten text is the literal "$" followed by the ORIGINAL text with its first character dropped. Because name(in:) accepts both "/" and "$" as openers, the rewrite is a no-op in meaning for text that already began with "$" and turns "/review the diff" into "$review the diff". Exactly one character is dropped, so a text of "/" alone becomes "$".
- **Persistence:** none
- **Cancellation:** not cancellable
- **Windows path:** String surgery on the first character, not a search and replace of the command name.
- **Verify by:** unit test asserting the exact rewritten string for a slash and for a dollar opener
