## Requirements

### PR-STORE-128 - A single model item is observed through its own box so siblings never re-render it
- **Source:** DroppyCode/Core/Support/ObservedValue.swift:4-13 - doc comment "One value under its own observation. A view that reads a thread or project through its cell depends on that item alone, so a change to any other item never re-renders it." then @MainActor @Observable final class ObservedValue<Value> { var value: Value; init(_ value: Value) }
- **Preconditions:** A list of projects or threads is on screen.
- **Action:** One item changes.
- **Expected:** Only the row reading that item’s box re-renders. The box holds exactly one property and is main-actor isolated.
- **Persistence:** none
- **Cancellation:** not cancellable
- **Windows path:** Per-item observable boxes rather than a whole-list signal. This is the mechanism that keeps a long sidebar cheap; a port that re-renders the whole list on any change will not meet the source’s scroll behaviour.
- **Verify by:** unit test counting row renders (each row body evaluated under observation tracking, R-OBS-4) when one thread's cell is written; the rename through the app model is PR-STORE-171
