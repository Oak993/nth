### PR-SETTINGS-093 - A provider is enabled unless it is listed as disabled, and re-enabling removes every duplicate entry
- **Source:** DroppyCode/App/AppSettings.swift:869-871 isEnabled(_:) - `!disabledProviders.contains(provider.rawValue)` | DroppyCode/App/AppSettings.swift:873-876 setEnabled(_:for:) - `disabledProviders.removeAll { $0 == provider.rawValue }; if !enabled { disabledProviders.append(provider.rawValue) }`
- **Preconditions:** The Providers page shows a provider's enable switch.
- **Action:** The user flips the switch.
- **Expected:** Every existing entry for that provider is removed first, then, only when switching off, one entry is appended. So the list never holds duplicates after a write, the order reflects the order providers were switched off, and a provider absent from the list is enabled. Setting a provider enabled when it was already enabled rewrites the same array, which still triggers a persist because the property's observer does not compare.
- **Side effects:** Persists the disabledProviders array on every flip, including a no-op flip
- **Persistence:** UserDefaults key "disabledProviders".
- **Cancellation:** not cancellable
- **Windows path:** Same remove-then-append. Keep the array, not a set, so the stored order matches.
- **Verify by:** unit test: disable twice, assert one entry; enable, assert zero

- **Preconditions:** Pairs exist for a provider.
