- **UI-TERM-011** Terminal drawer, top edge / Resize strip (slider)
  - geometry: Overlaid at .top, full width, .frame(height: 8). Covers the empty band above the tabs, not the tab row itself.
  - type: n/a
  - colour: Transparent; only the grip bar is drawn.
  - states: hover: grip widens to 28 and fades to opacity 0.6 over 0.18 s ease-out; dragging: grip stays shown even if the pointer leaves the strip; rest: grip 12 wide at opacity 0

- **UI-TERM-012** Terminal drawer, top edge / Resize grip bar (decoration)
  - geometry: Height 2.5, corner radius 1.25 (height / 2), width 12 at rest and 28 when shown, centred horizontally and vertically in the 8-point strip.
  - type: n/a
  - colour: NSColor.labelColor resolved in the current appearance, repainted on every effective-appearance change.
  - states: rest: width 12, opacity 0; shown (hover or drag): width 28, opacity 0.6; transitions animate over 0.18 s with an ease-out curve; layout-driven updates are applied with animations disabled
  - interactions: none of its own; it is a hover affordance for UI-TERM-011
