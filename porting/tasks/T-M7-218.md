## Requirements

### PR-TERM-011 - The selected session is the one whose id matches the thread's selection, falling back to the last session in the row
- **Source:** DroppyCode/App/Views/Terminal/TerminalStore.swift:113-116 selected(for:) - list.first matching selection[threadID], otherwise list.last
- **Preconditions:** The thread has one or more sessions.
- **Action:** The panel asks for the selected session.
- **Expected:** If selection[threadID] names a session still in the list, that one is selected. Otherwise the LAST session in the list is selected, so a stale or missing selection still shows a live tab. With no sessions at all, nil is returned and the empty state renders.
- **Persistence:** None; selection is in-memory per run.
- **Failure cases:** Selection names a removed session: the last session is shown instead, and the stale key is left in the dictionary.
- **Cancellation:** not cancellable
- **Windows path:** Same fallback, including leaving the stale key in place.
- **Verify by:** unit test on the store

### PR-TERM-037 - A session is identified by a fresh UUID and carries its thread, directory and title for its whole life
- **Source:** DroppyCode/App/Views/Terminal/TerminalStore.swift:7-12 - class TerminalSession: Identifiable with let id = UUID(), let threadID: UUID, let directory: String, var title: String, private(set) var isRunning = true
- **Preconditions:** None.
- **Action:** A session is created.
- **Expected:** id is a new UUID and never changes; threadID and directory are immutable; title is mutable but is only ever set at construction by the store; isRunning starts true and is only ever set to false, never back to true (a restart makes a new session instead).
- **Persistence:** Nothing about a session is persisted; every session is gone on quit.
- **Cancellation:** not cancellable
- **Windows path:** Same immutable identity and one-way isRunning.
- **Verify by:** unit test on the session model

### PR-TERM-038 - Each session creates its terminal view at a fixed 640 by 240 frame with a 12-point regular monospaced system font and Option treated as Meta

- **Preconditions:** A session is being created.
- **Action:** TerminalSession.init runs.
- **Expected:** The terminal view starts at 640 by 240 points (its real size comes from the host container immediately afterwards), renders in the system monospaced face at 12 points regular weight, and sends Option-modified keys as Meta escape sequences.
- **Persistence:** None; there is no user setting for terminal font or size anywhere in the source.
- **Cancellation:** not cancellable

### PR-TERM-039 - The session runs the user's login shell as resolved by LoginEnvironment.userShell()
- **Source:** DroppyCode/App/Views/Terminal/TerminalStore.swift:28 - let shell = LoginEnvironment.userShell() | DroppyCode/Core/Support/Shell.swift:425-435 userShell() - SHELL from the process environment if it is an executable file, else getpwuid(getuid()).pw_shell if it is an executable file, else the literal "/bin/zsh"
- **Preconditions:** None.
- **Action:** A session is created.
- **Expected:** The executable launched is the first of: the SHELL environment variable when it names an executable file, the login shell from the password database when it names an executable file, or the literal /bin/zsh.
- **Side effects:** One or two filesystem executability checks.
- **Persistence:** None.
- **Failure cases:** Neither source resolves: /bin/zsh is used even if it does not exist, and the launch fails.
- **Cancellation:** not cancellable
- **Windows path:** PLATFORM BOUNDARY, unresolved. Windows has no SHELL variable and no password-database login shell. Which interpreter the embedded terminal launches is part of UNK-0005 and must be an explicitly justified engineering decision, not a guessed default. The three-step precedence (explicit environment override, then user record, then a fixed fallback) is the source-defined shape to preserve.
- **Verify by:** contract fixture over the precedence chain
- **Depends on UNK-0005**, which is unresolved. Implement only the part the source settles; flag the rest.

### PR-TERM-040 - The shell inherits the captured login environment with exactly four variables overridden
- **Source:** DroppyCode/App/Views/Terminal/TerminalStore.swift:29-33 - var environment = LoginEnvironment.current; environment["TERM"] = "xterm-256color"; environment["COLORTERM"] = "truecolor"; environment["TERM_PROGRAM"] = "Droppy Code"; environment["DROPPY_CODE_PROJECT_ROOT"] = directory | DroppyCode/Core/Support/Shell.swift:331-335 - TERM, TERM_PROGRAM and COLORTERM are among the keys stripped from the captured login environment, so these three are always set by this code and never inherited
- **Preconditions:** None.
- **Action:** A session is created.
- **Expected:** The child receives the captured login environment plus exactly these four entries: TERM=xterm-256color, COLORTERM=truecolor, TERM_PROGRAM=Droppy Code, DROPPY_CODE_PROJECT_ROOT set to the session's directory. No other variable is added or removed here. Because the capture strips TERM, TERM_PROGRAM and COLORTERM, these assignments are always writes rather than overwrites.
- **Side effects:** User shell profiles and any tool the user runs can read DROPPY_CODE_PROJECT_ROOT and TERM_PROGRAM.
- **Persistence:** None, but the variable names are an external contract with whatever the user's shell configuration and scripts read.
- **Cancellation:** not cancellable
- **Windows path:** Same four names and values. TERM_PROGRAM's value and the DROPPY_CODE_ prefix are product-identity strings: the owner-approved rename covers product identity, so whether these two become Marrow-branded is an owner decision, not a porting choice. Until that decision is recorded, the source values are the specification. The precedent for keeping DROPPY_CODE_ prefixes on machine-readable contracts is porting/port_impacts.md:114 entry 53.
- **Verify by:** contract fixture asserting the child environment

### PR-TERM-041 - The environment dictionary is flattened to KEY=VALUE strings with no quoting or escaping
- **Source:** DroppyCode/App/Views/Terminal/TerminalStore.swift:34 - let pairs = environment.map { "\($0.key)=\($0.value)" } | DroppyCode/App/Views/Terminal/TerminalStore.swift:40 - the pairs array is passed as the environment argument to startProcess
- **Preconditions:** None.
- **Action:** A session is created.
- **Expected:** Each entry becomes one string of the key, an equals sign and the value, with no quoting, escaping or sorting. Dictionary iteration order is unspecified, so the order of the resulting array is not stable between runs; nothing in the source depends on it.
- **Persistence:** None.
- **Failure cases:** A value containing a newline or NUL is passed through as-is; the source performs no validation.
- **Cancellation:** not cancellable
- **Windows path:** Windows takes an environment block rather than an argv-style array; build it from the same map with no quoting. Platform boundary: Windows environment variable names are case-insensitive, so two keys differing only in case would collide where macOS keeps both.
- **Verify by:** unit test on the flattener

### PR-TERM-042 - The shell is launched as a login shell by setting argv[0] to a hyphen followed by the shell's file name

- **Preconditions:** None.
- **Action:** A session is created.
- **Expected:** argv[0] is a hyphen followed by the last path component of the shell executable (for example "-zsh" for /bin/zsh), which is the Unix convention that makes the shell read its login profile files.
- **Side effects:** The user's login profile files are executed inside the terminal.
- **Persistence:** None.
- **Cancellation:** not cancellable
- **Windows path:** PLATFORM BOUNDARY. Windows has no argv[0] login convention. This must be replaced consciously rather than translated: the stated intent is that the tab is a full interactive shell with the user's profile applied. Which interpreter and which profile mechanism is part of UNK-0005.
- **Verify by:** contract fixture asserting the launch vector
- **Depends on UNK-0005**, which is unresolved. Implement only the part the source settles; flag the rest.
