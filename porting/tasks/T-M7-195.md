### PR-SIDEBAR-018 - While the list is scrolling it takes no hover and no clicks; the freeze lifts 150 ms after the last movement
- **Source:** DroppyCode/App/Views/Sidebar/SidebarView.swift:112 - `.allowsHitTesting(!isListScrolling)` | DroppyCode/App/Views/Sidebar/SidebarView.swift:136-147 - `.onScrollPhaseChange { _, phase in if phase == .idle { scrollSettle?.cancel(); isListScrolling = false } else { noteListScroll() } }` and `.onScrollGeometryChange(for: CGFloat.self, of: { $0.contentOffset.y }) { old, new in if old != new { noteListScroll() } }` | DroppyCode/App/Views/Sidebar/SidebarView.swift:391-403 noteListScroll - `if !isListScrolling { isListScrolling = true }`, cancels and restarts a task that sleeps `.milliseconds(150)` then clears the flag if not cancelled and still set
- **Preconditions:** Sidebar list has enough content to scroll.
- **Action:** User scrolls the list with a wheel, trackpad or drag.
- **Expected:** Hit testing is disabled for the whole list for as long as scrolling continues and for 150 ms after the last movement. Wheel ticks report no scroll phase, so they keep the freeze alive through the contentOffset observer alone. A scroll phase reaching `.idle` cancels the settle task and lifts the freeze immediately rather than waiting the 150 ms. The flag is written only when it is currently false, so a continuous scroll costs one list evaluation, not one per frame.
- **Side effects:** Starts and cancels a debounce task on the main actor.
- **Persistence:** None.
- **Failure cases:** Task cancelled by a newer scroll: the older task returns without clearing the flag.
- **Cancellation:** The settle task is cancelled by every subsequent movement and by an idle phase.
- **Windows path:** A 150 ms debounce timer on the Windows list plus pointer-events suppression while it is armed. The idle-phase shortcut needs a Windows scroll-end signal (WM_MOUSEWHEEL has none; a scrollbar release or inertia-end from the input stack supplies it, and without one the 150 ms debounce alone governs). Platform boundary: scroll phase reporting.
- **Verify by:** interaction test that a click landing during a scroll is ignored and lands 150 ms later.
