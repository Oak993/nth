## UI contract records

Exact values. Do not round, restyle or substitute. Where a value is macOS-delegated, say so.

- **UI-WIN-078** Main window, Settings window and every hosted chat column / App zoom scaling of the hosted content (container)
  - geometry: Content laid out in the host's size divided by the scale (0.75, 0.9, 1, 1.1, 1.25, 1.5, 1.75 or 2), drawn scaled by the same factor about the top-leading corner, filling the host without clipping.
  - type: Every size inside the tree, text included, is drawn multiplied by the scale.
  - colour: Unchanged by the zoom.
  - states: one of eight levels; any other stored value draws at 100; 100: drawn at the stock size
  - interactions: none of its own; it follows the appZoom setting live, set by the zoom chords or the Settings card
