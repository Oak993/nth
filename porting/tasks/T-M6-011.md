## UI contract records

Exact values. Do not round, restyle or substitute. Where a value is macOS-delegated, say so.

- **UI-LAUNCH-001** Main window, shown by launch / The application's main window, created on first use and restored to its last frame (window)
  - text, verbatim: `Droppy Code`
  - geometry: Content size 1320 x 860 points on a first ever launch; content minimum size 860 x 560; afterwards the frame saved under the autosave name "DroppyCodeMainWindow"; centered on screen when no saved frame exists
  - type: Title bar type is system-provided; the window is created titled with a transparent title bar, specified by the shell and chrome area
  - colour: Clear window background with a SwiftUI glass pane over it (WindowManager.swift:4-8); resolved per theme by the shell and chrome area
  - states: First launch: no saved frame, so the window is centered at 1320 x 860; Subsequent launch: restored to the saved frame; Resized below the minimum: prevented by contentMinSize 860 x 560; Closed: the app keeps running and the window is recreated on reopen
  - interactions: Shown automatically at launch; Reopen from the Dock when no window is visible (applicationShouldHandleReopen); The Window menu item labelled with AppInfo.name shows it again (AppCommands.swift:21-25)
- **UI-LAUNCH-002** Welcome tour, presented over the main window at launch / The welcome tour window, presented 700 ms after launch on a first run (window)
  - geometry: Owned by TourWindowController; its geometry belongs to the tour area
  - type: Tour area
  - colour: Tour area
  - states: Not shown at all when the setting "hasSeenTour" is true; Shown once, 700 ms after launch, when "hasSeenTour" is absent or false; Finished: writes hasSeenTour = true; Closed without finishing: also writes hasSeenTour = true, so it never reappears
  - interactions: Appears automatically; no user action opens it at launch; The Help menu opens it again, outside this area
- **UI-LAUNCH-003** Settings window, About page, opened by launch after an update install / The Settings window opened on the About page on the first launch after an installed update (window)
  - geometry: Content size 780 x 580; centered over the main window, clamped to that window's screen visible frame; centered on screen when the main window is missing, hidden or miniaturised
  - type: Settings area
  - colour: Settings area
  - states: Not shown when there is no pending relaunch marker; Not shown when the stored version differs from the running build's version, and the marker is still consumed; Shown on the About page with the install celebration armed when the versions match
  - interactions: Opens automatically during launch; Also opened by tapping the update notification, which skips showing the main window first
- **UI-LAUNCH-005** System notification banner / The banner and sound the app asks for when a notification is delivered while it is running (notification banner)
  - geometry: System-drawn
  - type: System-drawn
  - colour: System-drawn
  - states: Suppressed entirely, no banner and no sound, when the notification's threadID equals the selected thread and the app is active; Banner plus default sound in every other case, including when the threadID is missing or unparseable and including the update notification
  - interactions: Tap on a thread notification: show the main window, select that thread, activate the app, in that order; Tap on an update notification: activate the app, then open Settings on About; the main window is NOT shown
