## Requirements

### PR-COMPOSER-069 - A thumbnail click toggles one shared preview panel per strip, and a second click on the same photo closes it
- **Source:** DroppyCode/UI/Common/AttachmentPreviewPanel.swift:19-70 AttachmentPreviewCoordinator - one NSPopover per strip, applicationDefined, animates; toggle closes when the same attachment id is already shown, otherwise shows | DroppyCode/App/Views/Chat/TimelineRows.swift:1282-1288 togglePanel | DroppyCode/UI/Common/AttachmentPreviewPanel.swift:258-295 AttachmentPreviewSlot builds the coordinator lazily on first open and inherits whichever anchor it already captured | porting/port_impacts.md:302 X4 - port both, and keep the laziness
- **Preconditions:** A strip with several attachments.
- **Action:** The user clicks one thumbnail, then another, then the same one again.
- **Expected:** One panel is shared: the first click opens it on that photo, clicking another swaps the content and re-shows at the new anchor, clicking the same photo again closes it. Rows that never open a panel never construct one.
- **Persistence:** Nothing persisted.
- **Failure cases:** No anchor resolvable: show returns and nothing opens.
- **Cancellation:** not cancellable
- **Windows path:** One shared non-activating popup per strip, constructed on first use, with the same toggle semantics.
- **Verify by:** interaction test clicking three thumbnails in sequence

### PR-COMPOSER-070 - The preview panel anchors to the tap point inside the strip, with the thumbnail and the strip as fallbacks
- **Source:** DroppyCode/UI/Common/AttachmentPreviewPanel.swift:117-147 anchorTarget - the strip anchor plus the current left-mouse-up event gives a 2 point wide rect at the tap's x spanning the strip's full height, clamped 2 points in from each edge; then the thumbnail's own bounds; then the strip's bounds; then the window rect anchor, again preferring the tap's x
- **Preconditions:** A preview is opening.
- **Action:** The panel picks its anchor.
- **Expected:** The arrow lands on the photo under the pointer. Keyboard or accessibility activation, which carries no click, falls back to the thumbnail's own bounds and then to the strip's.
- **Persistence:** Nothing persisted.
- **Failure cases:** A strip smaller than 8 by 8 points is not used as the tap anchor.
- **Cancellation:** not cancellable
- **Windows path:** Same four-step fallback. The 'current event' is the message being dispatched.
- **Verify by:** interaction test opening by click and by keyboard

### PR-COMPOSER-071 - The preview panel closes on a click outside the strip, on Escape, and when its window resigns key or moves
- **Source:** DroppyCode/UI/Common/AttachmentPreviewPanel.swift:160-201 startMonitors - a local mouse-down monitor, a local key-down monitor and three notification observers (didResignKey, willMove, didMove) on the anchor window; clicks inside the panel or anywhere on the strip pass through, any other click closes first and still reaches its target; key code 53 (Escape) closes and swallows the key
- **Preconditions:** A preview is open.
- **Action:** The user clicks elsewhere, presses Escape, switches windows or drags the window.
- **Expected:** The panel closes in each case. A click that closes it still reaches whatever it hit. Escape is consumed by the panel and does not reach the composer.
- **Persistence:** Nothing persisted.
- **Cancellation:** not cancellable
- **Windows path:** An app-scoped message filter in place of the NSEvent local monitors, which never see other applications' events; plus window activation and move notifications.
- **Verify by:** interaction test of all four dismissals

### PR-COMPOSER-072 - The preview panel is sized once before it opens and never resizes
- **Source:** DroppyCode/UI/Common/AttachmentPreviewPanel.swift:78-109 show - the image or video display size is computed first, contentSize comes from Self.contentSize, and setFixedContent installs the content at that size | DroppyCode/UI/Chrome/Popovers.swift:28-40 setFixedContent - sizingOptions = [] so the host never publishes a size; content is framed to the size, top-aligned and clipped | DroppyCode/UI/Common/AttachmentPreviewPanel.swift:223-235 contentSize - for a photo or a movie, imageBounds.width + 24 by ceil(imageSize.height) + 60; for a readable text file, 464 by min(320, max(120, textCount / 4)) + 60; otherwise 344 by 100
- **Preconditions:** An attachment is being previewed.
- **Action:** The panel opens.
- **Expected:** The panel's size is decided before it shows, from the same numbers the content lays out with, so the spinner and the loaded photo take the same room and the arrow never drifts. Content taller than measured is clipped at the bottom, never at the header.
- **Side effects:** Reads the image or video header, and up to 500,000 bytes of a text file
- **Persistence:** Nothing persisted.
- **Failure cases:** An unreadable image header falls back to a 4:3 aspect (AttachmentPreview.swift:246).; An unreadable video track falls back to the full 480 by 360 bounds (AttachmentPreview.swift:274).
- **Cancellation:** not cancellable
- **Windows path:** Same three size formulas and the same top-aligned clipping.
- **Verify by:** capture comparison of a portrait photo, a text file and a binary file preview
