### PR-HYDRA-016 - The in-turn budget checks run in a fixed order, and the out-of-turn backstop allows maxSeconds plus 90 seconds on an API-key provider

- **Preconditions:** A Droppy-run head whose HydraHeadInfo.kind is .droppy is running.

- **Failure cases:** An interrupt that does not take: the head stays running until its provider ends it
- **Cancellation:** The backstop's own interrupt is the cancellation path; a user stop takes precedence and finishes the head as stopped.
- **Windows path:** Reproduce the ordering exactly; a port that checks wrap-up before budget-spent would emit an extra note the macOS app never emits. The +90 s applies only to API-key-based providers.
