### PR-MCP-048 - MCPConnectionState has five cases and a server with no entry is notConnected
- **Source:** DroppyCode/Core/Models/MCP.swift:218-232 MCPConnectionState | DroppyCode/Services/MCP/MCPStore.swift:32-34 state(for:)
- **Preconditions:** none
- **Action:** The page asks for a server's state.
- **Expected:** states[id] when present, otherwise .notConnected. The cases are .notConnected, .connecting, .connected(toolCount: Int), .failed(message: String) and .needsSetup(MCPSetupGuide). isConnected is true only for .connected; isConnecting is true only for .connecting. The tool count rides inside the connected case, so a refresh that returns fewer tools changes the badge without touching the persisted connection until it is saved.
- **Side effects:** none
- **Persistence:** states live in memory only; at load, a connection with a non-nil connectedAt is restored as .connected(toolCount: tools.count)
- **Failure cases:** none
- **Cancellation:** not cancellable
- **Windows path:** A discriminated union in the renderer state, mirrored from the main process.
- **Verify by:** unit plus a restart test

### PR-MCP-084 - MCPPaths fixes the on-disk layout of every MCP file
- **Source:** DroppyCode/Core/Models/MCP.swift:236-253 MCPPaths | DroppyCode/Services/MCP/MCPProviderConfig.swift:238 geminiSettingsURL | DroppyCode/Services/MCP/MCPProxy.swift:15 portFile | DroppyCode/Services/MCP/MCPExternalSync.swift:52 managedURL
- **Preconditions:** none
- **Action:** Any MCP file is read or written.
- **Expected:** MCPPaths.directory is <data root>/mcp/ and is created with intermediate directories on first access. mcp.json and custom-mcp.json sit in <data root>, NOT inside mcp/. Inside mcp/ live exactly: claude.json ({"mcpServers": …}), codex.json ({"mcp_servers": …}), copilot.json ({"mcpServers": …}), gemini-settings.json ({"mcpServers": …}), proxy-port (a decimal UInt16 as UTF-8 text) and managed.json (the legacy migration list).
- **Side effects:** creating mcp/ on first access
- **Persistence:** this is the complete persisted file inventory for the area
- **Failure cases:** a directory that cannot be created leaves every write failing silently
- **Cancellation:** not cancellable
- **Windows path:** <data root> is %LOCALAPPDATA%\<AppName>\ and the mcp subdirectory is %LOCALAPPDATA%\<AppName>\mcp\. Putting mcp.json or custom-mcp.json inside mcp\ silently loses every connection and custom server. The bridge file, which macOS writes to <Application Support>/<AppName>/MCP/, collapses onto the same mcp\ folder on a case-insensitive filesystem and is written there (PR-MCP-193).
- **Verify by:** restart test plus a file-inventory assertion
