- **UI-WIN-001** Main window and Settings window, title bar / Close window button (the leading traffic light) (button)
  - geometry: 14 x 14 points. Sidebar wide enough: leading 18, top 16. Sidebar narrow or hidden: leading 14, top 21. Always the first of three at pitch 23.
  - type: Framework-drawn glyph; no type.
  - colour: Framework-drawn; follows the process appearance, which the theme sets to light, dark or system.
  - states: hover: the framework reveals the glyph; window inactive: the framework greys all three; always visible: isHidden is set false on every placement; moving: animates 0.32 s ease-out, 0.18 s with Reduce Motion, unanimated during a live resize or a sidebar-edge drag
  - interactions: upstream: click closes the window; the main window is hidden rather than released and the app keeps running; port: click on the main window quits the app, waiting first while a Hydra merge runs (OD-0008 C1); click on the Settings window closes it
- **UI-WIN-002** Main window and Settings window, title bar / Minimize window button (the middle traffic light) (button)
  - geometry: 14 x 14 points, at leading + 23 (so x = 41 beside the sidebar, x = 37 collapsed), same top as the close button.
  - type: Framework-drawn glyph; no type.
  - colour: Framework-drawn; follows the process appearance.
  - states: same four states as the close button
  - interactions: click minimizes the window
- **UI-WIN-003** Main window and Settings window, title bar / Zoom window button (the trailing traffic light) (button)
  - geometry: 14 x 14 points, at leading + 46 (x = 64 beside the sidebar, x = 60 collapsed), same top as the close button.
  - type: Framework-drawn glyph; no type.
  - colour: Framework-drawn; follows the process appearance.
  - states: disabled on the Settings window, which is created without the resizable style; same four states as the close button otherwise
  - interactions: click zooms or restores the main window
- **UI-WIN-004** Main window, between the sidebar and the chat / Sidebar resize strip with its grip bar and glow (slider)
  - geometry: Hit width 9 points, full pane height, starting 30 points below the pane's top (trafficLightTop 16 + trafficLightDiameter 14). Grip: 2.5 wide, corner radius 1.25, 10 tall at rest and 22 tall when shown, centred both ways. Glow: corner radius 4, x = bounds.minX + 0.5, y = 30, width = bounds.width - 1, height = bounds.height - 30, both floored at 0.
  - type: None.
  - colour: Grip and glow are both the system label color resolved in the view's effective appearance, re-resolved on an appearance change. Grip opacity 0.6 when shown, 0 otherwise. Glow opacity 0.05 hovered, 0.10 dragging, 0 otherwise.
  - states: rest: grip 10 tall and invisible, glow invisible; hover: grip 22 tall at 0.6, glow at 0.05; dragging: grip 22 tall at 0.6, glow at 0.10; inactive: no cursor rect, no hover, hit testing returns nothing at all
  - interactions: hover shows the column-resize cursor; press and drag resizes the sidebar, deltas measured from the press x in window space; release below 110 collapses the sidebar; release at or above 110 settles at max(210, width); acceptsFirstMouse: a single click-drag works on an inactive window; never moves the window, even where it overlaps the title bar band
