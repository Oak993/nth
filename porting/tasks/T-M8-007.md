### PR-UPDATE-021 - A background check that finds a newer version posts exactly one notification per version, ever

- **Action:** notifyOnce runs.
- **Expected:** If "updateChecker_notifiedVersion" already equals this version, nothing happens. Otherwise the key is set to this version FIRST, and only then is the banner scheduled. A manual check (background: false) never notifies, whatever it finds.

- **Cancellation:** not cancellable
- **Windows path:** Windows toast notification via Electron Notification. Keep the write-then-send order exactly, including its consequence.
- **Verify by:** interaction test

### PR-UPDATE-023 - Notification authorization is requested only when it has never been decided, and only at the moment of the first banner

- **Action:** The authorization status is read.

- **Cancellation:** not cancellable

- **Verify by:** interaction test
