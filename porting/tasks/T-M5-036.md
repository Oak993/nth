### PR-PROVREG-233 - The Login button writes a per-CLI login script into a temporary directory and opens it, silently doing nothing when the write fails
- **Source:** DroppyCode/UI/Common/Components.swift:117-132 openTerminal(running:) - the directory is the system temporary directory with "droppy-code-login" appended and is created with intermediate directories; the file name token is the first whitespace-separated word of the command with non-letters removed; the file is named "login.command" when that token is empty and otherwise "login-" plus the token plus ".command"; the contents are the literal shebang line for zsh with the login flag, then the command, then a newline; a write failure returns without opening anything; the file is given permissions 0755 and opened with the workspace
- **Preconditions:** The user clicked a Login button or the plan-limits Login button.
- **Action:** openTerminal runs.
- **Expected:** One script file per CLI, so a second login opened while the first shell still runs does not overwrite the script that shell is reading. For "cursor-agent login" the token is "cursoragent" because the hyphen is stripped, giving the file name login-cursoragent.command. A write failure produces no terminal and no message.
- **Side effects:** Creates a directory and a world-readable executable script in the temporary directory containing the login command; launches a terminal.
- **Persistence:** The script file persists in the temporary directory until the system clears it.
- **Failure cases:** Directory creation or file write fails: nothing opens and the user sees no feedback.
- **Cancellation:** not cancellable once the terminal opens; the app does not track the shell.
- **Windows path:** PLATFORM BOUNDARY: the zsh shebang, the .command extension, the POSIX permission bits and the workspace open verb all have no Windows equivalent. The Windows build must launch the command in a Windows terminal, and the per-CLI file naming rule should be preserved if a script file is used at all. The token derivation rule is a source fact and must be kept if file names are kept. OD-0012 F1: the temporary folder is named "marrow-login" in place of "droppy-code-login".
- **Verify by:** interaction test asserting the derived file name and the launched command
