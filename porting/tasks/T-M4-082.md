### PR-PROVCLI-199 - Copilot reads the files an apply_patch envelope touches from three header prefixes, keeping first occurrences
- **Source:** DroppyCode/Services/Providers/CopilotSession.swift:1034-1045 - patchPaths(_:)
- **Preconditions:** An apply_patch call whose patch text is the arguments themselves, or arguments.input, or arguments.patch.
- **Action:** patchPaths runs.
- **Expected:** The patch is split on newlines. For each line, the three prefixes "*** Update File: ", "*** Add File: " and "*** Delete File: " are tested in that order; a matching line yields the remainder trimmed of whitespace. Empty paths are skipped, and a path already seen is skipped, so the result is first-occurrence order with no duplicates.
- **Persistence:** none
- **Failure cases:** A patch with no headers yields no paths, so the title reads "Edit 0 files".
- **Cancellation:** not cancellable
- **Windows path:** Line splitting uses a newline predicate that also handles CR, so a CRLF patch is read correctly; the trailing trim then removes any stray CR from the path.
- **Verify by:** unit test over all three header kinds, a duplicate and an empty patch

### PR-PROVCLI-200 - Copilot parses a markdown checklist into todos, treating anything but x and blank as in progress
- **Source:** DroppyCode/Services/Providers/CopilotSession.swift:1047-1062 - the todoLinePattern and todos(from:)
- **Preconditions:** An update_todo call whose arguments.todos is a markdown string.
- **Action:** todos(from:) runs.
- **Expected:** Each line is trimmed and matched against ^(?:[-*+]|\d+[.)])\s*\[(.?)\]\s*(.+)$ - a bullet of -, * or +, or a number followed by . or ), then optional whitespace, a bracketed single optional character, optional whitespace, and at least one character of text. Lines that do not match are skipped. The bracket content lowercased: "x" -> .done; a single space or the empty string -> .pending; anything else -> .active. The text is the second capture.
- **Persistence:** none
- **Failure cases:** A non-matching line contributes nothing.
- **Cancellation:** not cancellable
- **Windows path:** The lowercasing must be invariant; a Turkish locale would map a dotted capital I differently and change which marker counts as done.
- **Verify by:** unit test over every bullet form and all three bracket states
