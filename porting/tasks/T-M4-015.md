### PR-MCP-049 - enabledServers is the enabled, previously connected set, resolved and sorted by id
- **Source:** DroppyCode/Services/MCP/MCPStore.swift:41-49 enabledServers
- **Preconditions:** Some connections exist.
- **Action:** exportAll runs, or a provider asks what servers it gets.
- **Expected:** From connections.values, keep those where isEnabled is true AND connectedAt is not nil; for each, look up entry(for: catalogID) and drop it when there is none (a custom that was deleted, or an id no longer in the catalog); resolve it with storedValues(for:); sort the results ascending by id. A server that is connecting for the first time is not included until its probe succeeds and writes connectedAt.
- **Side effects:** reading a secret field touches the credential store once per field
- **Persistence:** none by itself
- **Failure cases:** a connection whose entry is gone is silently skipped - it stays in mcp.json but reaches no provider
- **Cancellation:** not cancellable
- **Windows path:** Same filter, same drop-on-missing-entry, same ascending id sort. The sort is observable: it fixes key order in the provider config files.
- **Verify by:** unit plus contract fixture on file ordering

### PR-MCP-052 - value(for:of:) is a strict draft-then-store-then-default chain
- **Source:** DroppyCode/Services/MCP/MCPStore.swift:63-71 value(for:of:)
- **Preconditions:** A field of an entry.
- **Action:** The key panel or the custom editor renders a field.
- **Expected:** If drafts[entry.id]?[field.key] exists (even as the empty string) it wins outright and is returned. Otherwise, if field.kind is .secret, read the credential store for (entry.id, field.key) and return it when non-nil; if the kind is NOT .secret, read connections[entry.id]?.values[field.key] and return it when non-nil. These two are an if/else-if on kind, not a fallthrough: a .secret field never reads the connection's plaintext values, and a .text or .path field never reads the credential store. Failing all of that, return field.defaultValue, and failing that, the empty string.
- **Side effects:** one credential-store read per secret field render
- **Persistence:** none
- **Failure cases:** under a capture run the credential read returns nil, so a secret field shows its defaultValue or "" and never leaks a stored value
- **Cancellation:** not cancellable
- **Windows path:** Same three helpers, same strict branch on kind. Collapsing the branches would show a DSN stored in mcp.json in a secret field or vice versa.
- **Verify by:** unit covering the empty-string draft, a secret with only a plaintext value present, and a text field with only a credential-store value present

### PR-MCP-055 - storedValues overlays credential-store secrets on top of the connection's plaintext values
- **Source:** DroppyCode/Services/MCP/MCPStore.swift:293-301 storedValues(for:)
- **Preconditions:** A connected or connecting entry.
- **Action:** The store resolves an entry for a probe or an export.
- **Expected:** Start from connections[entry.id]?.values (or an empty map). For every field whose kind is .secret, read the credential store and, when non-nil, set values[field.key] to it. Drafts are NOT consulted here: resolve always uses what was committed by connect. A secret with no stored value leaves whatever plaintext value happened to be in the connection under that key.
- **Side effects:** one credential-store read per secret field of the entry
- **Persistence:** none
- **Failure cases:** a locked credential store yields nil and the placeholder resolves to the field default or empty, producing a config that will fail to authenticate
- **Cancellation:** not cancellable
- **Windows path:** Same overlay order.
- **Verify by:** unit

### PR-MCP-056 - connect cancels any probe in flight and marks the connection enabled
- **Source:** DroppyCode/Services/MCP/MCPStore.swift:86-89 connect(_:)
- **Preconditions:** A card's Connect, Sign in, Try again or the key panel's save is pressed.
- **Action:** connect(entry) runs.
- **Expected:** Any existing probe task for that id is cancelled first. The connection is the existing one or a new MCPConnection(catalogID: entry.id), and its isEnabled is forced to true - connecting a server that the user had switched off switches it back on.
- **Side effects:** cancels an in-flight probe task, which for a stdio probe terminates its child process through the probe's defer
- **Persistence:** the connection row is written by the save later in the same call
- **Failure cases:** none
- **Cancellation:** this IS the cancellation path for a previous probe
- **Windows path:** Same. The cancel must actually stop a running stdio probe and kill its child.
- **Verify by:** unit plus an interaction test pressing Connect twice quickly

### PR-MCP-057 - Pointing an OAuth server at a different address signs it out first
- **Source:** DroppyCode/Services/MCP/MCPStore.swift:92-96 connect's address-change branch
- **Preconditions:** An OAuth entry with a draft that changes a field used in its URL (in the shipped catalog only gitlab's instance).
- **Action:** The user edits the instance and presses Sign in.
- **Expected:** When entry.isOAuth and a draft exists, compare entry.oauthURL(values: connection.values) with entry.oauthURL(values: connection.values merged with the draft, draft winning). If they differ, call MCPOAuth.signOut(serverID:) - which deletes the credential-store items "MCP <id> oauth" and "MCP <id> oauth-client" - and MCPProxy.shared.unregister(serverID:). The browser flow then runs afresh against the new address.
- **Side effects:** two credential-store deletions; removes the proxy route for that id
- **Persistence:** the OAuth session and registered client for that server are destroyed
- **Failure cases:** none; a sign-out of a server that was never signed in is a no-op
- **Cancellation:** not cancellable
- **Windows path:** Same comparison of filled URLs, same two deletions from Windows Credential Manager (OD-0008 B3).
- **Verify by:** unit driving the two oauthURL values, plus an integration test that the token store is empty afterwards

### PR-MCP-058 - Retrying a failed OAuth server signs it out so the rejected token is not reused

- **Persistence:** the OAuth session is destroyed
- **Failure cases:** none
- **Cancellation:** not cancellable
- **Windows path:** Same. Protected storage is Windows Credential Manager (OD-0008 B3), under the same account strings.
- **Verify by:** interaction test: fail a sign-in, press Sign in again, assert a fresh browser flow is started
