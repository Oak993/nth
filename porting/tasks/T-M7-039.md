## UI contract records

Exact values. Do not round, restyle or substitute. Where a value is macOS-delegated, say so.

- **UI-GIT-054** Message editor / Undo file changes toggle (toggle)
  - text, verbatim: `Undo the file changes this thread made`
  - geometry: A switch-styled toggle at small control size whose label is an HStack with spacing 8: the wording, a spacer with a minimum of 8, the restorable file count and the statistics label, filling the available width.
  - type: Callout from the box.
  - colour: The count is Chrome.secondaryText; the statistics use the shared success and danger colours.
  - states: on by default; rendered only when the preview found restorable files
  - interactions: click toggles whether Send restores the files
- **UI-GIT-055** Message editor / File row (row)
  - geometry: Rows in a leading-aligned lazy stack with spacing 6; each is an HStack with spacing 8 holding an icon, the path, a spacer with a minimum of 4, and a trailing value. More than five files puts the rows in a scroll view of fixed height 110.
  - type: Caption.
  - colour: The icon and the Kept and Binary markers are Chrome.secondaryText; the statistics use the shared colours.
  - states: kept: the icon is "hand.raised" and the trailing value is the literal "Kept"; binary: the icon is "doc" and the trailing value is the literal "Binary"; otherwise: the icon is "doc" and the trailing value is the statistics label; dimmed to opacity 0.45 when the toggle is off or the file is kept, full opacity otherwise
  - interactions: hover shows a tooltip
- **UI-GIT-056** Message editor / Cancel and Send buttons (button)
  - text, verbatim: `Send`
  - geometry: The editor's action row: Cancel first, then Send.
  - type: Button roles.
  - colour: Cancel uses the glass style, Send the prominent glass style.
  - states: Send is disabled while the file check is still running, while the edit is empty, while a send is in flight and while the thread is running
  - interactions: Cancel closes the editor and discards the edit; Send reverts to this message and, when the files were restored as asked, sends the edited text
