## UI contract records

Exact values. Do not round, restyle or substitute. Where a value is macOS-delegated, say so.

- **UI-THEME-042** Link popover / Popover body (popover)
  - geometry: Width exactly 220, padding 6, rows stacked leading-aligned with spacing 0. Anchored below the clicked link's own glyph bounds. Fallback size 220 by 110 when the content measures non-positive.
  - type: Popover item styles.
  - colour: Popover chrome.
  - states: transient: an outside click dismisses it; moving to another link moves the same popover
  - interactions: Escape closes it, via a local key monitor on key code 53, because the rows take no focus
- **UI-THEME-043** Link popover / Merge row (menu item)
  - text, verbatim: `Merge <the request's own label>`
  - geometry: First row, followed by a divider, when the link is a merge or pull request and the chat can merge.
  - type: The word "Merge" semibold, the request label in the regular weight.
  - colour: Popover item colours; the leading accessory is the forge host's favicon once loaded.
  - states: shows an "arrow.triangle.merge" symbol until the favicon loads; absent entirely when the chat has no merge target
  - interactions: click closes the popover and hands the request to the chat
- **UI-THEME-044** Link popover / Open Link row (menu item)
  - text, verbatim: `Open Link`
  - geometry: Popover item row, 220 points wide inside 6 points of padding.
  - type: Popover item style.
  - colour: Popover item colours; leading symbol is the compass glyph.
  - states: always present
  - interactions: click opens via MarkdownLinkOpener: the default browser for almost every URL, or a local file for a scheme-less absolute path (PR-THEME-145)
- **UI-THEME-045** Link popover / Copy Link row (menu item)
  - text, verbatim: `Copy Link`
  - geometry: Popover item row, last in the list.
  - type: Popover item style.
  - colour: Popover item colours; leading symbol is the link glyph.
  - states: always present
  - interactions: click clears the clipboard and writes the URL's absolute string as plain text
