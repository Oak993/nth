## UI contract records

Exact values. Do not round, restyle or substitute. Where a value is macOS-delegated, say so.

- **UI-THEME-040** Chat, a rendered paragraph / Link run (link)
  - text, verbatim: `<the pretty title, or the author's own link text>`
  - geometry: Inline in the paragraph; preceded by a 14 by 14 favicon attachment and one space when the host's icon is cached.
  - type: Bold, always, at the paragraph's own point size; other inline intents (italic, code) are preserved alongside.
  - colour: Chrome.accentNSColor, reapplied on every render so a theme change recolours links already on screen. Underline style is explicitly 0.
  - states: hover raises the pointing-hand cursor; while streaming, drawn at the veil's alpha in the accent rather than in the text colour
  - interactions: click opens the URL in the default browser; right-click or control-click opens the link popover anchored under the words; text selection includes the link
- **UI-THEME-041** Chat, a rendered paragraph / Link favicon (image)
  - geometry: 14 by 14 points, baseline offset by the base font's descender plus 1, immediately before the link text, followed by one space.
  - type: n/a
  - colour: The site's own icon, with a white background plate flood-filled to transparency and its fringe un-premultiplied.
  - states: absent until the icon has been fetched and cached; appears after a revision bump rebuilds the paragraph
  - interactions: part of the link run; clicking it opens the link
- **UI-THEME-046** Chat, a rendered paragraph / Head mention chip (inline chip)
  - text, verbatim: `<the head's persona name>`
  - geometry: Native path: a dragon glyph at (base point size times 1.25) rounded, baseline offset by the descender plus 1, then one space, then the name. Text path: the glyph at a fixed 16 points with a baseline offset of -3.2 points (`-(size * 0.2)`, MarkdownView.swift:386); the comment at :385 says the offset lifts the glyph, which disagrees with the negative value (see PR-THEME-177). The port reproduces -3.2.
  - type: The name in the bold face.
  - colour: Glyph and name both in the persona's own colour, never the accent.
  - states: hovering for 250 ms shows the head's card, anchored to the name's glyph bounds; the cursor stays the normal arrow, unlike a link
  - interactions: click opens that head's chat, without moving the text selection
