- **UI-RUNTIME-017** Composer, chat box / The /plan command, typed or picked from the suggestions (command)
  - text, verbatim: `/plan`
  - geometry: This area defines the outgoing text, not the chip. ComposerDraft.outgoingText builds the head as "/" followed by the command name; with an empty body the head alone goes out, with quotes present the head is joined to the body by two newlines, and otherwise by a single space (ThreadRuntime.swift:122-135). The chip that stands for a DraftCommand is drawn by the composer view, outside this area.
  - type: Set by the composer, outside this area.
  - colour: Set by the composer, outside this area.
  - states: Recognised only when the whole trimmed outgoing text is exactly "/plan"; "/plan something" is sent to the provider instead. Recognised on every send path: the composer send, the follow-up queue drain, send-now and the Return-captured pending send.
  - interactions: Sending it toggles ChatThread.interactionMode between .plan and .build and records "plan" in the provider recency list. No turn starts and no message reaches the provider.
