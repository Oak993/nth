### PR-TERM-067 - The top script is the selected thread's project's first script; its menu item does not exist in the port and the command stays on its chord
- **Source:** DroppyCode/App/AppModel.swift:1089-1092 topScript - nil unless a thread is selected and resolves; otherwise project.scripts.first | DroppyCode/App/AppCommands.swift:89-94 - Button titled model.topScript.map { "Run \($0.name)" } ?? "Run top script", action guards on topScript and selectedThreadID then calls model.runScript, with the .runScript keyboard shortcut and .disabled(model.topScript == nil) | DroppyCode/Core/Models/Shortcuts.swift:224 - .runScript default chord is KeyChord(keyCode: 15, modifiers: .command), which is Command-R
- **Preconditions:** A thread may or may not be selected.
- **Action:** The user presses the Run top script chord.
- **Expected:** topScript is nil unless a thread is selected and resolves, otherwise the project's first script. Upstream shows a menu item reading "Run " followed by that script's name, or exactly "Run top script" and disabled when there is none, with the default chord Command-R. DEVIATION (OD-0008 C3): the port has no menu bar, so there is no such item and no item title. The command stays on its chord (Ctrl+R by default, OD-0008 B7): with a top script and a selected thread it runs the first script exactly as the popover row does; otherwise it does nothing. The source's command palette has no Run top script row (DroppyCode/App/Views/Palette/CommandPalette.swift:153-178 lists New thread, New thread in worktree, Add project, the three thread actions Toggle terminal, Toggle changes and finish, and Settings), so none is added.
- **Side effects:** A shell process is launched and the drawer is shown.
- **Persistence:** None.
- **Failure cases:** No selected thread or no scripts: the chord does nothing.
- **Cancellation:** not cancellable
- **Windows path:** No menu item. The chord handler keeps the item's guard (model.topScript and model.selectedThreadID) and calls runScript.
- **Verify by:** interaction test pressing the chord with and without scripts, plus an assertion that no menu bar exists
