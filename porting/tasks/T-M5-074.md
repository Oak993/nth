## Requirements

### PR-THEME-043 - Shortcut sections carry fixed tints that are not theme-derived: threads blue, window purple
- **Source:** DroppyCode/UI/Theme/ShortcutTint.swift:1-12 `extension AppShortcut.Section { var tint: Color { switch self { case .threads: Chrome.blue; case .window: Color(red: 0.686, green: 0.322, blue: 0.871) } } }` | DroppyCode/UI/Chrome/Chrome.swift:119 `static let blue = Color(red: 0.040, green: 0.478, blue: 1.000)`
- **Preconditions:** The keyboard-shortcut list in Settings is on screen.
- **Action:** A shortcut section header or row is drawn.
- **Expected:** The threads section is tinted with the fixed blue Color(red: 0.040, green: 0.478, blue: 1.000); the window section with the fixed purple Color(red: 0.686, green: 0.322, blue: 0.871) (approximately #AF52DE). Neither follows the theme accent. The switch covers exactly two sections, so only those two exist at this commit. The purple is written as floating-point components, not a hex string, unlike every colour in AppTheme.
- **Persistence:** not persisted
- **Failure cases:** None expressed in source: the switch is exhaustive over two cases.
- **Cancellation:** not cancellable
- **Windows path:** Two literal colours. These are the only colours in the theme area declared in floating-point components; they are declared without an explicit colour space and so take the framework default, which is sRGB, the same space AppTheme's hex colours use.
- **Verify by:** unit: the two component triples
