### PR-PROVCLI-121 - Codex maps item types to tool rows, with command actions deciding read, search or command
- **Source:** DroppyCode/Services/Providers/CodexSession.swift:812-864 - toolCall(from:)
- **Preconditions:** An item from item/started or item/completed.
- **Action:** toolCall builds the row.
- **Expected:** "commandExecution": the command is unwrapped of its shell prefix; the set of commandActions types decides the row - a set exactly equal to ["read"] with a first action carrying a path gives .read titled with that path made relative and the command as the detail; a non-empty set that is a SUBSET of ["search", "listFiles"] gives .search titled with the command; otherwise .command titled with the command. "fileChange": .edit titled with the single relative path, or "Edit <n> files" when there is not exactly one. "mcpToolCall": .mcp titled "<server> · <tool>" defaulting to "MCP" and "tool", detail the compact arguments unless that string is "null". "dynamicToolCall": .other titled item.tool or "Tool". "webSearch": .web titled item.query or "Web search". "collabAgentToolCall": .agent whose verb comes from the table spawnAgent -> "Send out a head", sendInput / sendMessage / followupTask -> "Brief a head", wait -> "Wait for heads", closeAgent / interruptAgent -> "Recall a head", resumeAgent -> "Resume a head", listAgents -> "List heads", default -> "Agent"; the title is the prompt flattened to at most 90 characters when present, with the verb as the detail, else the verb as the title with no detail. "subAgentActivity": nil, deliberately, because as rows they only doubled the head's report pill. "imageView": .read titled with the relative item.path or the literal "Image". "imageGeneration": .other titled item.revisedPrompt or "Generate image". "enteredReviewMode" and "exitedReviewMode": .other titled "Review" with item.review as the detail. Anything else: nil.
- **Persistence:** none
- **Failure cases:** An unmapped item type draws no row.
- **Cancellation:** not cancellable
- **Windows path:** unwrapShell strips the literal prefixes "/bin/zsh -lc ", "/bin/bash -lc ", "bash -lc ", "zsh -lc ", "/bin/sh -c " and "sh -c " and the surrounding quotes. On Windows the CLI may wrap commands differently; the prefix list is a PRODUCT constant applied to text the CLI produced and is reproduced as is, since removing an entry changes what the user reads.
- **Verify by:** unit test over every item type including the three commandExecution shapes
