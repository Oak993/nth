### PR-SETTINGS-263 - A watchdog task started by the first active report polls every 2 seconds and drops timelines whose reporter is gone or resting
- **Source:** DroppyCode/UI/Common/RenderBudget.swift:23 - @ObservationIgnored private var watch: Task<Void, Never>? | DroppyCode/UI/Common/RenderBudget.swift:44-63 - if now, watch == nil { watch = Task { @MainActor [weak self] in while !Task.isCancelled { try? await Task.sleep(for: .seconds(2)); guard let self, !Task.isCancelled else { return }; for id in Array(scrolling) { guard let reporter = reporters[id]?.object, reporter.isScrollingNow else { scrolling.remove(id); reporters[id] = nil; continue } }; let still = !scrolling.isEmpty; if still != isScrolling { isScrolling = still }; if !still { watch = nil; return } } } }
- **Preconditions:** At least one timeline has just reported true and no watchdog is running.
- **Action:** Two seconds elapse with the set non-empty.
- **Expected:** At most one watchdog exists at a time: it is created only when the flag has just become true AND watch is nil. It sleeps FIRST and checks afterwards, so a stale reporter survives at least one full 2 second period. Each pass iterates a COPY of the id set (Array(scrolling)) so it can mutate the set while iterating; for each id it drops both the id and the reporter entry when the weak reporter has gone OR when the live reporter answers isScrollingNow == false; a reporter that answers true is left alone. After the sweep it recomputes the union and publishes it only on a change. When the set has emptied it clears its own handle (watch = nil) and returns, so the next active report starts a fresh task. The task holds self weakly and returns immediately if self is gone or the task was cancelled.
- **Persistence:** None. ScrollActivity holds no persisted state; everything it tracks dies with the process.
- **Cancellation:** not cancellable
- **Windows path:** A single timer or interval, at most one at a time, fixed at 2000 milliseconds, that sleeps before its first check, sweeps over a snapshot of the ids, removes dead or resting reporters, republishes the union and then clears itself when nothing is left. Do not shorten the period or check before the first sleep: a reporter is expected to be briefly registered and resting between a drag and its coast. No caller in the pinned tree does this (SettingsScrollTracker.swift:25 and ThreadTimeline.swift:1054 both pass reporter: self), so the port must keep passing a reporter on every true report.
- **Verify by:** unit test with a fake clock: register a reporter that answers isScrollingNow false, assert the app is still scrolling before 2 s and no longer scrolling after one period, and assert only one watchdog is ever created across repeated start reports
