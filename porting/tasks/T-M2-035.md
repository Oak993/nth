### PR-PROVREG-015 - Codex executable name is codex
- **Source:** DroppyCode/Core/Models/Provider.swift:42 executableName - case .codex returns "codex"
- **Preconditions:** Provider is not API-key based.
- **Action:** executable(for:) looks the CLI up on PATH.
- **Expected:** The bare name searched is exactly "codex". The same string is the placeholder of the Binary path field for this section.
- **Side effects:** A PATH walk; no process launch.
- **Persistence:** None.
- **Failure cases:** Not found on PATH and there are no fallback candidates for codex, so executable(for:) returns nil and the provider reads as not installed.
- **Cancellation:** not cancellable
- **Windows path:** PATH is split on ';' and each candidate is tried against PATHEXT (codex.cmd, codex.exe) instead of the POSIX execute-bit test. Platform boundary: executable resolution. Executable identity is validated per PA-0016: PATH resolution honours PATHEXT, and a candidate whose Windows version resource identifies it as the command interpreter (CompanyName Microsoft Corporation with OriginalFilename Cmd.Exe/Cmd.Exe.MUI, or FileDescription Windows Command Processor), or which is %SystemRoot%\System32\cmd.exe or %SystemRoot%\SysWOW64\cmd.exe, is rejected and the provider reports not installed.
- **Verify by:** contract fixture over a synthetic PATH
