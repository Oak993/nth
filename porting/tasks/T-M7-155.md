### PR-MCP-220 - The setup panel is idempotent per server and only refocuses when it is already up for that server
- **Source:** DroppyCode/App/Views/Settings/MCPSetupPanel.swift:18-43 isPresenting and present | DroppyCode/App/Views/Settings/MCPSetupPanel.swift:45-49 close
- **Preconditions:** A server is in the needsSetup state.
- **Action:** present runs, possibly repeatedly.
- **Expected:** isPresenting is true when the panel is visible AND its recorded entry id equals this entry's. When it is, the panel is simply ordered front and nothing else happens - the browser page is not reopened and the steps are not rebuilt under the user. Otherwise the entry id is recorded, the guide's page is opened in the browser, the content is measured at 400 points wide, and the panel is built, sized, placed and ordered front. close() clears the recorded id and orders the panel out.
- **Side effects:** on a first presentation, opens the guide page in the browser
- **Persistence:** none
- **Failure cases:** none
- **Cancellation:** not cancellable
- **Windows path:** Keep the guard; a failing re-check must not reopen the browser.
- **Verify by:** interaction test pressing Check again twice and asserting one browser tab

### PR-MCP-221 - The setup panel follows its own content height, keeping its top edge fixed
- **Source:** DroppyCode/App/Views/Settings/MCPSetupPanel.swift:53-61 fit(height:) | DroppyCode/App/Views/Settings/MCPSetupPanel.swift:183-185 the geometry observation
- **Preconditions:** The setup panel is visible.
- **Action:** Its content grows or shrinks, for example when the status line appears or the success view replaces the steps.
- **Expected:** The reported content height is rounded up and floored at 100. When it differs from the panel's current height by more than one point, the panel's frame origin y is raised by the difference and the height is set, so the top edge stays where it is and the panel grows downward. Nothing happens when the panel is not visible.
- **Side effects:** resizes the floating panel
- **Persistence:** none
- **Failure cases:** none
- **Cancellation:** not cancellable
- **Windows path:** Same top-anchored resize. Note macOS y coordinates grow upward; on Windows the equivalent is keeping the top edge and extending the bottom.
- **Verify by:** interaction test driving a failed re-check and asserting the top edge does not move
