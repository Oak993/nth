### PR-COMPOSER-125 - Dragging the knob snaps to the nearest stop and fires an alignment haptic on each change
- **Source:** DroppyCode/App/Views/Composer/EffortSlider.swift:801-818 DragGesture(minimumDistance: 0) - the first change sets dragX inside .spring(response: 0.22, dampingFraction: 0.8), later changes set it directly; nearestStop is taken and, when it differs from the index, the index is written and NSHapticFeedbackManager performs .alignment at .now; onEnded clears dragX inside .spring(response: 0.32, dampingFraction: 0.78) | DroppyCode/App/Views/Composer/EffortSlider.swift:833-836 nearestStop = min(count - 1, max(0, Int(((x - inset) / step).rounded())))
- **Preconditions:** A slider with two or more stops.
- **Action:** The user presses anywhere on the track and drags.
- **Expected:** A press with no movement already moves the knob, because the minimum distance is zero. The knob follows the pointer, clamped to the insets, and the selected index is the nearest stop by rounding. The knob springs into the pointer on the first change (response 0.22, damping 0.8) and springs back to its resting stop on release (response 0.32, damping 0.78). Each index change fires an alignment haptic.
- **Side effects:** Haptic feedback on each stop crossed
- **Persistence:** Through the binding, the thread's effort and the model preference.
- **Failure cases:** count <= 1 or step <= 0: nearestStop returns 0.
- **Cancellation:** A gesture cancelled from under the pointer leaves dragX set until the next gesture; there is no separate cancellation handler here.
- **Windows path:** Same springs and the same rounding. Haptics have no Windows equivalent and are dropped silently, never substituted with sound (port_impacts X8(e)).
- **Verify by:** interaction test dragging across all stops
