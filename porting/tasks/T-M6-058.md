- **Persistence:** The thread's timeline is rewritten and saved by revert.
- **Failure cases:** revert throws: the notice reads "The stopped message was kept: " followed by the localized error description, and the draft is not repopulated.; The user types while the stop lands: draft.isEmpty fails the re-check and the stopped turn stays in the thread.; The turn left the thread while polling: nothing happens.

- **Windows path:** Same guards, same 200 x 50 ms watchdog. The localized error description comes from the Windows error surface.
- **Verify by:** integration test with a scripted agent that ignores the stop for five seconds
