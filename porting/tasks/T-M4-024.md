### PR-PROVACP-052 - baseModelID strips everything from the first opening bracket
- **Source:** DroppyCode/Services/Providers/ACPSession.swift:432-436 - `guard let bracket = id.firstIndex(of: "[") else { return id }; return String(id[..<bracket])`; comment: Cursor's parameterized IDs are `model[effort=high,...]`; the picker stores the base name
- **Preconditions:** A model id string.
- **Action:** baseModelID runs.
- **Expected:** An id with no "[" is returned unchanged. Otherwise everything from the FIRST "[" onward is dropped, including the bracket. No trimming, no closing-bracket requirement. The function itself is unconditional; the Cursor gate is at each call site via usesParameterizedModels, except at :307 and :343 and :350 and :387 where it is applied for every provider.
- **Persistence:** None.
- **Failure cases:** A non-Cursor model id that legitimately contains "[" is truncated at the comparison sites.
- **Cancellation:** not cancellable
- **Windows path:** Same.
- **Verify by:** unit

### PR-PROVACP-053 - sameModel compares base ids and is false whenever either side is nil
- **Source:** DroppyCode/Services/Providers/ACPSession.swift:438-441 - `guard let lhs, let rhs else { return false }; return baseModelID(lhs) == baseModelID(rhs)`
- **Preconditions:** Two optional model ids.
- **Action:** sameModel runs.
- **Expected:** Two nils compare as DIFFERENT, not equal. Otherwise the comparison is on base ids, for every provider, so `gpt-5[effort=high]` and `gpt-5` are the same model. Consequences: with currentModel nil, applySelection always sends a model change, and the post-pass of PR-PROVACP-050 updates no model.
- **Persistence:** None.
- **Cancellation:** not cancellable
- **Windows path:** Same, including the nil-nil false result.
- **Verify by:** unit

### PR-PROVACP-056 - A model change prefers session/set_config_option and is skipped when the base ids already match
- **Source:** DroppyCode/Services/Providers/ACPSession.swift:446-454 - `let wireID = usesParameterizedModels ? Self.baseModelID(model) : model; if !Self.sameModel(wireID, currentModel) { if let modelConfigID { await setConfigOption(modelConfigID, value: wireID) } else { _ = try? await connection.request("session/set_model", ["sessionId": .string(sessionID), "modelId": .string(wireID)]) }; currentModel = wireID }`
- **Preconditions:** A non-empty model is requested.
- **Action:** applySelection applies it.
- **Expected:** The wire id is the base id for Cursor and the raw id for the other three. When sameModel(wireID, currentModel) is true nothing is sent. Otherwise, if a model config option id was discovered, the change goes through session/set_config_option with that configId; only when no config id exists does it fall back to session/set_model with the parameters sessionId and modelId. currentModel is set to wireID in either branch, and also when the fallback request fails, because the request is `try?` and the assignment follows it unconditionally.
- **Side effects:** One request per actual change.
- **Persistence:** None.
- **Failure cases:** A rejected session/set_model is swallowed by `try?`, yet currentModel is updated, so the app believes the model changed when it did not and will not retry.
- **Cancellation:** not cancellable
- **Windows path:** Same, including the optimistic currentModel assignment after a swallowed failure.
- **Verify by:** contract fixture (both branches, plus a rejected set_model)

### PR-PROVACP-057 - An effort change needs a non-empty effort, a discovered effort config id, and a different current effort

- **Cancellation:** not cancellable

### PR-PROVACP-058 - The Fast toggle is written as the strings true and false on every turn where it differs
- **Source:** DroppyCode/Services/Providers/ACPSession.swift:460-466 - `if let fastConfigID { let wanted = fastMode ? "true" : "false"; if wanted != currentFast { await setConfigOption(fastConfigID, value: wanted); currentFast = wanted } }`

- **Action:** applySelection applies the turn's fastMode flag.

- **Side effects:** One session/set_config_option request when the value differs.
- **Persistence:** None.

- **Cancellation:** not cancellable
- **Windows path:** Same. The value must be a JSON string.
- **Verify by:** contract fixture (assert the string literals)
