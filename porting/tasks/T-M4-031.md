### PR-PROVACP-122 - A search row is titled by the pattern from five keys, with the folder as its detail
- **Source:** DroppyCode/Services/Providers/ACPSession.swift:723-726 - `let pattern = Self.string(in: raw, keys: ["pattern", "query", "glob", "regex", "search"]); call.title = pattern ?? title.nilIfEmpty ?? path ?? - **Preconditions:** A tool call of kind .search.
- **Action:** makeToolCall titles the row.
- **Expected:** The pattern is the first non-empty trimmed string among exactly these five keys in order: pattern, query, glob, regex, search. The title is the pattern, else the cleaned agent title if non-empty, else the path, else the empty string. The detail is set to the path only when all four conditions hold: a pattern was found OR the agent title was non-empty; a path exists; the path differs from the working directory; and the path differs from the chosen title.
- **Persistence:** Title and detail are persisted with the tool call.
- **Cancellation:** not cancellable
- **Windows path:** Same five keys and the same four-part detail condition.
- **Verify by:** unit (key table plus the four detail conditions)
