## UI contract records

Exact values. Do not round, restyle or substitute. Where a value is macOS-delegated, say so.

- **UI-SIDEBAR-052** Project settings page (the only writer of project.icon, which the sidebar reads) / Project icon button (button)
  - geometry: the mark at `size` inside a frame of size + 9 square, with a 6 pt continuous rounded content shape; default size 13
  - type: the mark is drawn with .system(size: size)
  - colour: Chrome.primaryText at 0.9
  - states: shows the picked emoji or symbol, or folder.fill when none is picked
  - interactions: click opens the picker popover below the button
- **UI-SIDEBAR-053** Project icon picker popover / Picker container (popover)
  - text, verbatim: `Project icon`
  - geometry: frame 300x420; padding 12; VStack(alignment: .leading, spacing: 10); the scrolling stack has 14 pt between sections and 1 pt of vertical padding; scroll indicators never
  - type: heading .system(size: 12, weight: .medium)
  - colour: heading Chrome.primaryText; the divider above the bottom row is overlaid with Chrome.overlay(0.12)
  - states: empty query (Emoji, Popular and every catalogue group); non-empty query (a single Symbols grid)
  - interactions: type in the search field; click a tile to set the icon; click the Folder tile to clear it
- **UI-SIDEBAR-054** Project icon picker popover / Symbol search field (field)
  - text, verbatim: `Search symbols`
  - geometry: HStack spacing 6; padding horizontal 8, vertical 5; background a 6 pt continuous rounded rectangle
  - type: magnifier .system(size: 11); text .system(size: 12) plain style
  - colour: magnifier Chrome.secondaryText; background Chrome.overlay(0.10)
  - states: empty (the sectioned view); with a query (the Symbols grid); whitespace-only is treated as empty
  - interactions: type to filter symbol names, compared case-insensitively with locale rules
- **UI-SIDEBAR-055** Project icon picker popover / Section heading (label)
  - text, verbatim: `Emoji | Popular | Symbols`
  - geometry: VStack(alignment: .leading, spacing: 5) above its grid
  - type: .system(size: 10, weight: .medium)
  - colour: Chrome.secondaryText
  - states: one per section
  - interactions: none
- **UI-SIDEBAR-056** Project icon picker popover / Icon tile (button)
  - geometry: 26x26 in a nine-column grid of fixed 26 pt columns, 4 pt between columns and 4 pt between rows; 6 pt continuous corner radius for the fill, the border and the content shape
  - type: emoji .system(size: 15); symbol .system(size: 12)
  - colour: symbol Chrome.primaryText at 0.9; fill Chrome.overlay(0.14) while hovered or selected, otherwise transparent; selected border Chrome.accent stroked at 1.5 pt
  - states: idle; hovered (fill, animated with Chrome.hover); selected (fill plus the accent border)
  - interactions: click sets project.icon to that emoji or symbol
- **UI-SIDEBAR-057** Project icon picker popover / Folder reset row (button)
  - text, verbatim: `Folder`
  - geometry: below the divider; HStack spacing 8 with a trailing Spacer(minLength: 0); the tile is a 26x26 IconTile
  - type: label .system(size: 12); the tile's glyph .system(size: 12)
  - colour: label and glyph Chrome.secondaryText
  - states: the tile is shown selected while project.icon is nil
  - interactions: click the tile sets project.icon to nil, returning the project to the default folder mark
