### PR-MCP-173 - Copilot arguments pass the config inline, disable the user's own servers by name, and disable built-ins only for github
- **Source:** DroppyCode/Services/MCP/MCPSessionOverrides.swift:4-12 copilotUserServerNames | DroppyCode/Services/MCP/MCPSessionOverrides.swift:14-30 copilotArguments
- **Preconditions:** A Copilot session is starting.
- **Action:** copilotArguments is built.
- **Expected:** Return an empty array immediately when copilotConfigJSON is nil. Otherwise ids = the keys of mcpServers inside that JSON string, and the arguments are built in this exact order: "--additional-mcp-config" then the whole compact JSON as one argument; then, for each name from copilotUserServerNames (the sorted keys of mcpServers in ~/.copilot/mcp-config.json) that is NOT in ids, the pair "--disable-mcp-server" and that name; then "--disable-builtin-mcps" appended only when ids contains the exact id "github".
- **Side effects:** one read of ~/.copilot/mcp-config.json
- **Persistence:** none
- **Failure cases:** an unreadable user config yields no disable flags
- **Cancellation:** not cancellable
- **Windows path:** Same order and the same conditional flag. The JSON argument must be passed as one argv element; a shell-quoted command line would mangle it.
- **Verify by:** unit over the three argument groups plus a launch test asserting the argument vector

### PR-MCP-174 - OpenCode receives its whole configuration through an environment variable rebuilt from claude.json
- **Source:** DroppyCode/Services/MCP/MCPSessionOverrides.swift:32-71 opencodeEnvironment | DroppyCode/Services/MCP/MCPSessionOverrides.swift:73-83 stringArray and stringMap
- **Preconditions:** An OpenCode session is starting.
- **Action:** opencodeEnvironment is built.
- **Expected:** Return an empty map when claude.json is missing, unparseable, or its mcpServers object is empty. For each member: when "type" is "http", emit {"type": "remote", "url": <url or the empty string>, "enabled": true} plus "headers" only when non-empty; otherwise require a non-empty "command" string or SKIP the member entirely, and emit {"type": "local", "command": [<command>] + <args>, "enabled": true} - command is an ARRAY whose first element is the executable - plus "environment" (not "env") only when non-empty. Return an empty map again when nothing was built. The root object is {"$schema": "https://opencode.ai/config.json", "mcp": <the map>}, serialized with sorted keys, returned as ["OPENCODE_CONFIG_CONTENT": <that JSON string>]. Only string values survive the header and environment conversions; non-string values are dropped.
- **Side effects:** one file read
- **Persistence:** none; the value rides in the child environment
- **Failure cases:** a local entry with an empty command is dropped silently
- **Cancellation:** not cancellable
- **Windows path:** Same key names, the command-as-array shape and the "environment" spelling. The whole JSON must survive environment-block construction; Windows environment variables have a large but finite size, so a very long configuration is a real limit to note.
- **Verify by:** contract fixture comparing the emitted JSON string

### PR-PROVCLI-136 - Copilot MCP overrides pass the whole config JSON as one token, disable user servers by name and drop the builtins for github
- **Source:** DroppyCode/Services/MCP/MCPSessionOverrides.swift:14-30 - copilotArguments() | DroppyCode/Services/Providers/CopilotSession.swift:484-486 - the comment and the append | porting/extracts/provider-argv-and-handshakes.md section 3.1
- **Preconditions:** MCP settings may or may not produce a Copilot config JSON.
- **Action:** connect builds the argv.
- **Expected:** When MCPProviderConfig.copilotConfigJSON() returns nil, NOTHING AT ALL is appended. Otherwise: the ids are the keys of the parsed root.mcpServers, or the empty set when parsing fails; the first two tokens are "--additional-mcp-config" and the ENTIRE config JSON text as ONE argv token; then, for every name in copilotUserServerNames() that is NOT among those ids, the pair "--disable-mcp-server" and that name, in whatever order copilotUserServerNames() yields; then, only when the ids contain the literal id "github", the single token "--disable-builtin-mcps".
- **Side effects:** The user's own MCP servers are switched off for this session by name, with their file untouched
- **Persistence:** none written here
- **Failure cases:** A config JSON that fails to parse still passes --additional-mcp-config with that text, and disables every user server, because the id set is empty.
- **Cancellation:** not cancellable
- **Windows path:** A whole JSON document as one argv token is the hardest Windows quoting case in this area: it contains double quotes, backslashes in any Windows paths inside it, and possibly a trailing backslash before the closing quote. Escaping is the port's problem; the source uses a process API with no shell and must not gain one (port_impacts.md entry 5 of the ordering list).
- **Verify by:** contract fixture asserting the child receives the exact JSON text, with a config containing Windows paths
