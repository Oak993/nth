## UI contract records

Exact values. Do not round, restyle or substitute. Where a value is macOS-delegated, say so.

- **UI-SIDEBAR-011** Sidebar, any row with actions / Row ellipsis button (button)
  - geometry: RowAccessoryIcon: 20x20 frame with a rectangular content shape
  - type: Chrome.inlineIconFont = .system(.subheadline, weight: .semibold) at B2 (Chrome.swift:29; 11 pt at the default size)
  - colour: Chrome.secondaryText
  - states: visible while hovered or while its popover is open
  - interactions: click toggles a popover menu anchored below the button (arrowEdge .bottom)
- **UI-SIDEBAR-012** Popover menu (any row's ellipsis) / Popover menu container (popover)
  - geometry: VStack(alignment: .leading, spacing: 0) with padding 6; frame minWidth 210, maxWidth 360, leading aligned; inside a ScrollView with maxHeight 460 and bounce based on size
  - type: inherited per item
  - colour: system popover material; buttons take the capsule border shape and the theme accent tint through presentedChrome()
  - states: short content sizes to fit; content over 460 pt scrolls
  - interactions: click away to dismiss
- **UI-SIDEBAR-013** Popover menu / Popover menu item (menu item)
  - geometry: HStack spacing 8; optional 14 pt checkmark column; 16 pt glyph column; title; Spacer(minLength: 16); optional detail; padding horizontal 8; height 26; 6 pt continuous corner radius
  - type: title .system(.body); symbol .system(.callout); detail .system(.callout); check column .system(.subheadline, weight: .semibold); confirmation check .system(.callout, weight: .semibold) (13, 12, 12, 11 and 12 pt at the default size)
  - colour: Chrome.danger when destructive, otherwise Chrome.primaryText; detail Chrome.secondaryText (at B2 the label colour at 0.7, ED-062); hover fill Chrome.overlay(0.1)
  - states: idle; hovered (fill, animated with Chrome.hover); disabled (opacity 0.4, no hover fill); confirmed (the label is replaced by the confirmation text with a green checkmark; unused by sidebar actions)
  - interactions: click runs the action one main-actor turn after the popover closes
