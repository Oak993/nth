ProviderGenerationComposer now builds from the host's trusted installed items and imported skills for Claude, Codex, Copilot, OpenCode/Go, Pi, Command Code, Grok and native APIs. Uncertain OpenCode source ordering leaves the optional bundle out. Plugin descriptors now supply their explicit root when composed. No vendor catalogue facts are inferred or changed.

SkillSessionFactory binds the existing family adapters, launch paths and native tools. ThreadRuntime passes explicit owning paths and the per-chat request_tool offer flow, builds generations for both new and resumed CLI/native sessions, and releases failed/cancelled preparations. Session reuse verifies its generation. Every newly bound CLI family implements ISkillSessionLifetime: RPC EOF and Stop do not stand in for actual child exit. Command Code retains all per-turn readers; Codex/Copilot retain the connection even after failed initialization/Stop. The next launch awaits the preceding readers before replacing a chat's generation. Core's additive JSONRPCConnection.ChildExited exposes process completion without changing protocol behaviour. Native requests receive names/descriptions, with bodies read only on invocation.
