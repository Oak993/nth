Pause, Cancel, Retry (ED)

Items download one at a time, as in OD-0100’s update run. Pause stops the current file where it is, and Resume carries on from there (downloads are resumable, plan 3.2). Cancel stops the rest, and what is already downloaded stays. A failed item doesn’t stop the others. At the end, Retry downloads just the failed items again.
