 * wallpaper into a texture; pass 2 draws the same picture to the screen and, wherever a glass shape sits, refracts that
 * texture through the shape the way the two reference repos do (OD-0107). When the wallpaper moves, both passes run every
 * frame; that is the cost this page measures.
 *

 *   (P'(x,y) = P(x + scale*(R-.5), y + scale*(B-.5))) with the base scale -180, read once per colour channel at
 *   slightly different strengths, which is the colour fringe. Here the total offset is clamped to a few pixels.
