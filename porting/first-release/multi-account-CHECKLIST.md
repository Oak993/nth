## CONFLICTS (page vs NOTES vs OD — both quotes)

1. **Pills visibility.** OD-0117: "Pills section in settings will be visible to users who have single accounts connected as well, just the options will be disabled…". Page: comment "the Pills page once 2 or more accounts or services are connected" and code hides the nav item unless `multi() || services() >= 2` (`multi-account.html:3739-3747`); NOTES:47 "Pills only once 2+ services are connected (Create a pill in the popover footer)". Page and NOTES agree; OD-0117 amends them. Builders: OD-0117 wins; the page needs an update (disabled-Pills copy is "not on page").
2. **Default of automatic switching / Handshake.** OD-0116: "automatic switching (\"Keep me going\", the Handshake into another account) is off by default for every service… switched off by default, app asks user the first time". Page: `SET = { …, hs: true, …}` (`multi-account.html:1766`) and "Use the Handshake" desc "…On by default." (`multi-account.html:3687`); NOTES:32 "on by default (it spends a sliver…)". NOTES:44-45 recommend "Keep me going" as the visible choice. "Keep me going" itself has no live default on the page (`SET.run = null`, `multi-account.html:1766`; unset desc `:3635`), so the conflict is specifically over the Handshake switch and any "Recommended" framing of Keep me going (`multi-account.html:3627`).
3. **Per-account Handshake control.** NOTES:56: "a per-account point lives in the account's row menu and shows as a small quiet note on the row only when it differs from the default". Page: settings foot says "open its ⋯ menu and choose Handshake at" (`multi-account.html:3733`) but every row also carries a visible Handshake button showing "<value> · uses default" (`multi-account.html:3793-3797, 3835, 3845`). Page shows the control on the row always; NOTES says a note only when different.
4. **Pill-in-composer styles.** NOTES:52: "Settings > Customization gets \"Pill in the composer: Merged capsule (default) / Name below / Lights only / Segmented rim\"". Page offers twelve: Merged capsule, Name below, Lights only, Segmented rim, Orbit, Liquid fill, Stacked marks, Aurora rim, Dial, Minimal, Glow rim, Glow rim · original colours (`multi-account.html:2142-2154`). OD-0115 keeps page version 8 as the finalized page, so OD-0115 wins; NOTES:52 is stale.
