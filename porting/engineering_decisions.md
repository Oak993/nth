
## ED-178

[UI] A lone CubicKeyframe (run3 stop of UI.Common.Genie; PR-THEME-175). SOURCE FACT: Genie.swift:155-168 animates with `.keyframeAnimator(initialValue: start, trigger: hasStarted) { ... } keyframes: { _ in CubicKeyframe(end, duration: GenieAnimator.duration) }`: one cubic keyframe, no startVelocity or endVelocity, no neighbours. Apple documents that without velocities SwiftUI computes them so motion stays smooth and that adjacent cubic keyframes form a Catmull-Rom spline; it does not state the end rule. DECISION: the segment is a Catmull-Rom spline with the endpoints duplicated (the standard end rule), i.e. a cubic Hermite from start to end with both tangents (end - start) / 2 per unit of normalized time: value(t) = start + (end - start) * (-t^3 + 1.5 t^2 + 0.5 t), t = elapsed / duration clamped to [0, 1]. Genie implements it as a private helper at the call site citing this ED (the only CubicKeyframe in the source; RowGlide.swift:225's SpringKeyframe is a different keyframe and is not decided here). Oracle O-62 parks the choice; Genie's curve tests carry it. ENGINEERING DECISION; not a deviation.

## ED-179

[UI][FOUNDATION] New foundation unit F.SymbolImage: SwiftUI Image(systemName:) and Image(_ name:) as port types in Marrow.UI (run4 stop 1 of UI.Chrome.Chrome; OD-0010, PA-0012). SOURCE FACT: the pinned source draws SF Symbols at 184 systemName:, 19 systemImage: and 3 systemSymbolName: sites (PA-0012), plus the project-icon picker's catalogue, and three asset-catalogue images, Image("droppy-logo"), Image("hydra-mark") and Image("badge-edit") (DroppyCode/Resources/Assets.xcassets). OD-0010 maps every SF Symbol to a Lucide icon through porting/icons/sf-symbols-to-lucide.json and the 714 SVGs in porting/icons/lucide (lucide-static 1.47.0, ISC). DECISION: (1) The SVGs and the mapping JSON are copied to src/Marrow.UI/Assets/Icons/ and embedded as Avalonia resources; the unit may add exactly `<AvaloniaResource Include="Assets/Icons/**" />` and `<AvaloniaResource Include="Assets/Images/**" />` to src/Marrow.UI/Marrow.UI.csproj (the only protected-file edit it makes). No NuGet package: a small converter turns the SVG elements Lucide uses (path d, circle, ellipse, line, polyline, polygon, rect with rx and ry) into Avalonia geometry in the 24-unit view box, stroked as Lucide draws (stroke width 2, round caps and joins, current colour), and the mapping's variant, fill_rendering and composed_rendering fields are honoured as porting/icons/README.md defines them. (2) Sizing and weight follow OD-0010, PA-0012 and the README; where they do not settle a value a call site needs, the unit stops and the orchestrator rules. (3) The three asset images are extracted from the pinned Assets.xcassets into src/Marrow.UI/Assets/Images/ in the form the catalogue holds (vector kept as vector where the catalogue has one), except where an owner decision names Marrow's own artwork for that image (OD-0015). (4) Port surface in src/Marrow.UI/Port/SwiftImage.cs: SwiftImage.SystemName(string) and SwiftImage.Named(string), plus the members call sites use (the SwiftUI image modifiers the packet's call sites apply). An unknown symbol name renders nothing, as SwiftUI does. Tests carry Decision ED-179. ENGINEERING DECISION.
